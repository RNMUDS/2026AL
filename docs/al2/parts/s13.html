プログラムをフローチャートで読む

第13回と第14回は、後期に作ってきたプログラムを「設計図」で読み、「テスト」で確かめる回です。 第13回はフローチャート、第14回はテストを扱います。 発展課題に取り組んでいる人は、作品4（自由テーマ）の設計と実装を進める回でもあります。

料理のレシピは「材料を切る → 炒める → 味を見る → 足りなければ塩を足す」のように、 順番と分かれ道で書かれています。 プログラムも同じで、処理の順番と、条件によって分かれる場所を絵にしたものがフローチャートです。 コードを1行ずつ読むより、全体の流れがひと目で分かります。

フローチャートを描く手順

順番やることコードのどこを見るか
1「開始」と「終了」の角丸を、上と下に置く─
2上から順に、処理の四角を置いて矢印でつなぐ関数の呼び出しと print。1つの四角に1つの仕事
3if のところにひし形を置き、「はい」「いいえ」の矢印を分けるif / else
4for や while は、下から上へ戻る矢印にするくり返しの終わりから始めへ
5アルゴリズム（探索・最短経路・全探索）が働く四角に色を付ける第2〜12回で学んだ関数

細かい行（変数を1つ用意する、など）は四角にしません。 「何をしているか」を人に説明するときに言う単位で四角を作ります。 テンプレートAなら、上の図のように8個ほどで足ります。

発展課題（作品4・自由テーマ）に取り組む人へ

自由テーマの作品は、いきなり完成品を作ろうとするとうまくいきません。 次の4ステップでまわします。第13回で①と②、第14回で③と④です。

動く最小版とは

「動く最小版」とは、やりたいことの中心だけができている状態のことです。 たとえば迷路ゲームなら、次のものが最小版になります。

最小版に入れるものあとで足すもの
迷路が1つあるステージが3つある
プレイヤーの道を1つ受け取る何度でも遊び直せる
最短の道と比べて点数を出すランキングを保存する
結果を文字で表示する色を付けてきれいに表示する

最小版が動いてから足していけば、途中で止まっても「動くもの」が手元に残ります。 AI に頼むときも、最初は最小版だけを頼み、動いてから1つずつ足すのがいちばん確実です。

テーマの決め方

テーマが思いつかないときは、次の3つの問いから考えてみてください。

  1. 自分が毎日している「順番を決めること」は何か（買い物、部活の練習メニュー、朝の支度）
  2. 自分がよく遊ぶゲームの中に、最短や最適が出てくる場面はないか（敵の追いかけ方、アイテム集め）
  3. 身のまわりの地図で、時間や料金が違う道はないか（自宅から大学、キャンパス内の移動）

大きな作品である必要はありません。小さくても、動いて、アルゴリズムが役に立っていることが大切です。 2つのテンプレートのどちらかを Gradio の画面に載せ替えるだけでも、作品4になります。

例題 1

テンプレートA: コスト付き迷路ゲーム

プレイヤーが選んだ道と、ダイクストラ法が見つけた最短の道を比べて点数を付けるゲームです。 cost_map と player_moves を書き換えれば、自分のステージが作れます。

例題1（参考）── 完成したコード。コメントなしで全体の流れをつかむ。保存するなら AL2-13-ex1-ref.py の名前で

Python ── AL2-13-ex1-ref.py
import heapq

cost_map = [
    [1, 1, 5, 9, 9, 1, 1, 1],
    [9, 1, 5, 1, 1, 1, 9, 1],
    [1, 1, 1, 1, 9, 1, 9, 1],
    [1, 9, 9, 5, 9, 1, 1, 1],
    [1, 1, 5, 5, 1, 1, 9, 5],
    [9, 1, 1, 9, 1, 9, 9, 1],
    [1, 1, 9, 9, 1, 1, 1, 1],
    [5, 1, 1, 1, 1, 9, 5, 1],
]

player_moves = "DDRRDDRRDDRRDR"

rows = len(cost_map)
cols = len(cost_map[0])
start = (0, 0)
goal = (rows - 1, cols - 1)
INF = float("inf")

def move_to_route(moves):
    """"DDRR..." のような文字列を、通るマスの並びに変える"""
    route = [start]
    r, c = start
    for move in moves:
        if move == "D":
            r = r + 1
        elif move == "U":
            r = r - 1
        elif move == "R":
            c = c + 1
        elif move == "L":
            c = c - 1
        if r < 0 or r >= rows or c < 0 or c >= cols:
            return None
        route.append((r, c))
    return route

def route_cost(route):
    """通った順番 route の合計コストを返す（スタートのマスは数えない）"""
    total = 0
    for i in range(1, len(route)):
        r, c = route[i]
        total = total + cost_map[r][c]
    return total

def solve():
    """ダイクストラ法で最小コスト経路を求める"""
    distance = {}
    came_from = {}
    for r in range(rows):
        for c in range(cols):
            distance[(r, c)] = INF
            came_from[(r, c)] = None
    distance[start] = 0
    queue = [(0, start)]
    settled = set()
    while len(queue) > 0:
        total, current = heapq.heappop(queue)
        if current in settled:
            continue
        settled.add(current)
        r, c = current
        for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            nr = r + dr
            nc = c + dc
            if nr < 0 or nr >= rows or nc < 0 or nc >= cols:
                continue
            if total + cost_map[nr][nc] < distance[(nr, nc)]:
                distance[(nr, nc)] = total + cost_map[nr][nc]
                came_from[(nr, nc)] = current
                heapq.heappush(queue, (distance[(nr, nc)], (nr, nc)))
    route = []
    node = goal
    while node is not None:
        route.append(node)
        node = came_from[node]
    route.reverse()
    return route, distance[goal]

def draw(route, title):
    """通り道に * を付けて迷路を表示する"""
    print(title)
    for r in range(rows):
        line = ""
        for c in range(cols):
            if (r, c) in route:
                line = line + f"{cost_map[r][c]:>3}*"
            else:
                line = line + f"{cost_map[r][c]:>3} "
        print("  " + line)
    print()

print("=" * 46)
print("  コスト迷路ゲーム  ステージ1")
print("=" * 46)
print("  1 = 舗装路(1秒)  5 = 砂地(5秒)  9 = 沼(9秒)")
print("  左上(S)から右下(G)まで、できるだけ短い時間で行こう")
print()

best_route, best_cost = solve()
player_route = move_to_route(player_moves)

if player_route is None:
    print("プレイヤーの道は迷路の外に出てしまった")
elif player_route[-1] != goal:
    print("プレイヤーの道はゴールに着いていない")
else:
    player_cost = route_cost(player_route)
    draw(player_route, f"プレイヤーの道: {len(player_route)-1}歩 ／ {player_cost}秒")
    draw(best_route, f"最短の道: {len(best_route)-1}歩 ／ {best_cost}秒")

    print("-" * 46)
    print(f"  プレイヤー: {player_cost}秒")
    print(f"  最短:       {best_cost}秒")
    score = int(best_cost / player_cost * 100)
    print(f"  スコア: {score}点（最短と同じなら100点）")
    if score == 100:
        print("  評価: 完璧！ 最短の道を見つけた")
    elif score >= 80:
        print("  評価: あと少し。もっと短い道がある")
    else:
        print("  評価: 沼をよけると、ぐっと短くなる")
    print("-" * 46)

穴ヒント候補（1つが正解）
穴1迷路の外に出たかどうかを調べるA. r == 0 and c == 0
B. r < 0 or r >= rows or c < 0 or c >= cols
C. r > rows or c > cols
穴2となりのマスへ行く合計が、表の値より短いときだけ書き直すA. total < distance[(nr, nc)]
B. cost_map[nr][nc] < distance[(nr, nc)]
C. total + cost_map[nr][nc] < distance[(nr, nc)]
穴3（合計秒数, マス）の組を入れる。秒数で並ぶようにするA. ((nr, nc), distance[(nr, nc)])
B. (distance[(nr, nc)], (nr, nc))
C. distance[(nr, nc)]

テンプレートB: 配達ルート最適化アプリ

配達先を並べると、貪欲法と全探索の両方でルートを作って比べるアプリです。 places を書き換えれば、自分の配達先が作れます（8件までなら全探索が使えます）。

例題2（参考）── 完成したコード。コメントなしで全体の流れをつかむ。保存するなら AL2-13-ex2-ref.py の名前で

Python ── AL2-13-ex2-ref.py
import math
import time
from itertools import permutations

places = [
    ("営業所", 5, 5),
    ("田中宅", 12, 3),
    ("鈴木宅", 2, 11),
    ("佐藤宅", 15, 12),
    ("高橋宅", 8, 14),
    ("伊藤宅", 19, 1),
    ("渡辺宅", 1, 2),
]

n = len(places)

def pad(text, width):
    """全角文字を2文字ぶんとして数え、右側に空白を足して表示の幅をそろえる"""
    length = 0
    for ch in text:
        if ord(ch) > 0x2000:
            length = length + 2
        else:
            length = length + 1
    return text + " " * (width - length)

distance = []
for i in range(n):
    row = []
    for j in range(n):
        d = math.sqrt((places[i][1] - places[j][1]) ** 2 + (places[i][2] - places[j][2]) ** 2)
        row.append(d)
    distance.append(row)

def route_length(order):
    """0番から出発し、order の順に回って0番へ戻るまでの合計距離を返す"""
    total = 0.0
    here = 0
    for city in order:
        total = total + distance[here][city]
        here = city
    return total + distance[here][0]

def greedy():
    """貪欲法: いまいる場所からいちばん近いところへ進むことをくり返す"""
    visited = [0]
    here = 0
    while len(visited) < n:
        nearest = None
        for j in range(n):
            if j in visited:
                continue
            if nearest is None or distance[here][j] < distance[here][nearest]:
                nearest = j
        visited.append(nearest)
        here = nearest
    return tuple(visited[1:])

def brute_force():
    """全探索: すべての順番を試して、いちばん短いものを返す"""
    best = None
    best_order = None
    for order in permutations(range(1, n)):
        value = route_length(order)
        if best is None or value < best:
            best = value
            best_order = order
    return best_order

def show(order, title):
    """ルートと合計距離を表示する"""
    print(title)
    names = [places[0][0]]
    for city in order:
        names.append(places[city][0])
    names.append(places[0][0])
    print("  " + " → ".join(names))
    print(f"  合計距離: {round(route_length(order), 1)}")
    print()
