ダイクストラ法の考え方

第4回では、辺に区間ごとにかかる時間（分）を書いた路線図（重み付きグラフ）で、 「合計時間がいちばん短い道」をさがしました。 幅優先探索は、その時間を使わずに、路線の本数がいちばん少ない道を求めます。 新宿から品川へは、品川が新宿のとなりなので最初に見つかり、答えは直通（路線1本・30分）に決まりました。 あとから渋谷で乗りかえる16分の道が出てきても、品川はもう見つけた駅なので書き直しません。 全探索は正しい道（16分）を選べますが、地図が少し大きくなるだけで、調べる行き方の数が爆発的に増えます。 そこで第5回は、行き方を全部は調べずに、合計時間がいちばん短い道を求める方法を学びます。 全部調べなくてよいのは、出発点から近い駅の順に時間を決めていくからです。 近い順に決めていけば、ある駅の時間を決めた時点で、まだ決めていない駅を回って来る行き方はそれより長くなるとわかるので、 その行き方を最後までたどる必要がありません（くわしい理由は、下の「いちばん小さい駅を確定してよい理由」で説明します）。 この方法がダイクストラ法です。1959年にエドガー・ダイクストラが考えた方法で、 今のカーナビや乗換案内の中でも使われています。

重み付きグラフと、幅優先探索・ダイクストラ法の関係

重み付きグラフは、辺（路線）に時間やコストの数字（重み）が書いてある地図のことです。 同じ重み付きグラフでも、どちらの方法を使うかで「いちばん短い道」の意味が変わります。

幅優先探索（第1〜3回）ダイクストラ法（第5回）
いちばん少なくするもの路線の本数合計時間（重みの合計）
重み（時間）を使うか使わない使う
使えないとき時間がいちばん短い道を求めたいとき重みにマイナスがあるとき
新宿 → 品川 の答え直通（路線1本・30分）渋谷経由（路線2本・16分）
出発点から各駅までの所要時間を、鉛筆で表に書いていく場面を思い浮かべてください。 最初はどの駅も「わからない」ので空欄です。 調べていくうちに「渋谷は7分で行ける」と分かれば書き込み、 あとで「もっと早い行き方があった」と分かれば、消して書き直します。 「この駅はもう書き直さない」と言い切れた駅から順に、ペンでなぞって確定させていきます。 これがダイクストラ法です。 第4回の全探索は、「新宿→品川」「新宿→渋谷→品川」「新宿→池袋→上野→東京→品川」のように、 行き方を1本ずつ最後までたどって合計時間を比べました。 行き方がちがえば同じ駅を何度も通るので、同じ駅を何度も調べ直すことになります。 ダイクストラ法では、1つの駅からとなりの駅を調べるのは、その駅を確定させたときの1回だけです。 駅が6つなら、調べるのは6回で終わります。

用語

用語意味路線図でいうと
距離表出発点から各頂点までの、今わかっているいちばん小さい合計コストを書いた表新宿から各駅まで、今わかっている最短の時間
確定距離表の値が「もう変わらない」と決まることペンでなぞった駅
書き直し（緩和）もっと小さい合計コストが見つかったときに、距離表の値を小さく書き直すこと品川 30分 → 16分（渋谷で乗りかえるほうが早い）
inf（無限大）「まだ行き方が1つも見つかっていない」ことを表す印。表では「－」と書くまだ空欄の駅

ダイクストラ法で使う3つの入れもの

名前中身最初の状態
distance距離表。出発点からその駅までの、今わかっているいちばん短い時間出発点だけ0、ほかはすべて inf（無限大）
settled「もう変わらない」と決まった（確定した）駅を入れる集合空

inf は Python で float("inf") と書く「無限大」の値です。 どんな数と比べても必ず大きくなるので、「まだ行き方が1つも見つかっていない」ことを表すのに使えます。

手計算で1手順ずつたどる

第4回の路線図で、新宿から各駅までの時間をダイクストラ法で求めます。 紙に6駅ぶんの表を書き、新宿だけ 0、ほかは「－」から始めます。 1つの手順でやることは、①まだ確定していない駅のうち時間がいちばん小さい駅を選ぶ、②その駅を確定する、 ③その駅のとなりの駅について「確定した駅の時間 ＋ 区間の時間」を計算し、表の値より小さければ書き直す、の3つです。

いちばん小さい駅を確定してよい理由

手順の②で「もう変わらない」と決めてしまってよいのは、重み（区間の時間）がすべて0以上だからです。 手順4で、まだ確定していない駅のうち時間がいちばん小さいのは品川（16分）でした。 確定済みの駅（新宿・渋谷・池袋）から品川へ直接来る行き方は、もう表に書き込んで比べてあります（直通 30分、渋谷経由 16分）。 それ以外の行き方は、確定済みの駅を出たあと、必ず未確定の上野を通ります（東京へも上野か品川を通らないと行けません）。 上野まででもう21分かかり、そこから品川へ進むと、重みが0以上なので時間はさらに増えます。 つまり16分より短くなることはありえません。

成り立たなくなる場合: 重みにマイナスの値が混ざると、上の理由が使えなくなります。 「遠回りをすると時間が減る」ことが起きてしまうためです。 後期の路線図や迷路、今回のディズニーランドの地図では、時間がマイナスになることはないので安心して使えます。

# 出発点から各駅までの「合計時間がいちばん短い行き方」の時間を求める。

# 第4回と同じ重み付きグラフ（数字は乗車時間・分）
railway = {
    "新宿": [("渋谷", 7), ("池袋", 9), ("品川", 30)],
    "渋谷": [("新宿", 7), ("品川", 9)],
    "池袋": [("新宿", 9), ("上野", 12)],
    "上野": [("池袋", 12), ("東京", 6)],
    "東京": [("上野", 6), ("品川", 11)],
    "品川": [("新宿", 30), ("渋谷", 9), ("東京", 11)],
}

start = "新宿"
INF = float("inf")      # inf は無限大。「まだ行き方が1つも見つかっていない」印に使う

# distance = 距離表。出発点からその駅までの、今わかっているいちばん短い時間
distance = {}
for station in railway:
    distance[station] = INF
distance[start] = 0     # 出発点だけは 0分

# settled = 「もう変わらない」と決まった（確定した）駅を入れる集合
settled = set()
# 手順ごとの記録（窓の表示に使う）。dict( ) と set( ) でその時の中身を写して残す
#   （写さずに distance をそのまま入れると、あとで書き直したときに記録まで変わってしまう）
log = [(None, dict(distance), set(settled), [])]

print(f"ダイクストラ法で、{start}から各駅までの最短時間を求める")
print("-" * 52)
step = 0                # 手順の番号（①②③を1回やるごとに1つ増える）
while len(settled) < len(railway):
    step = step + 1

    # ① まだ確定していない駅のうち、時間がいちばん小さい駅を選ぶ
    current = None
    for station in railway:
        if station in settled or distance[station] == INF:
            continue
        if current is None or distance[station] < distance[current]:   # いちばん小さい駅を残す
            current = station
    if current is None:
        break                   # 残りの駅には、どこからも行けない

    # ② 選んだ駅を確定する（この駅の時間は、もう変わらない）
    settled.add(current)
    print(f"手順{step}  {current}（{distance[current]}分）を確定")

    # ③ となりの駅について、current を通るほうが短ければ書き直す
    changes = []
    for name, minutes in railway[current]:     # name = となりの駅、minutes = その区間の時間
        if name in settled:
            continue
        new_distance = distance[current] + minutes      # current までの時間 ＋ その区間の時間
        if new_distance < distance[name]:               # 今の表の値より短いときだけ書き直す
            old = distance[name]
            distance[name] = new_distance
            changes.append((name, old, new_distance, minutes))
            if old == INF:
                print(f"        {name} に {new_distance}分 を書き込んだ（{current} {distance[current]} + {minutes}）")
            else:
                print(f"        {name} を {old}分 → {new_distance}分 に書き直した（{current} {distance[current]} + {minutes}）")
    log.append((current, dict(distance), set(settled), changes))

print("-" * 52)
print(f"{start}から各駅までの最短時間")
for station in railway:
    print(f"  {station}: {distance[station]}分")

def _graph_parts(graph):
    """隣接リストから、丸にする場所の名前と、線（場所, 場所, 時間）の一覧を作る。"""

        if final_distance.get(name, INF) == INF:
            out.append(f"{name} へは行けない（道がつながっていない）")
    return out


def _crossings(order, edges):
    """円の上に order の順で頂点を並べたとき、線どうしが何回交わるかを数える。"""
    at = {name: i for i, name in enumerate(order)}
    count = 0
    for i, (a, b, _) in enumerate(edges):
        lo, hi = sorted((at[a], at[b]))
        for c, d, _ in edges[i + 1:]:
            if len({a, b, c, d}) < 4:
                continue
            inside = (lo < at[c] < hi) + (lo < at[d] < hi)
            count += inside == 1
    return count


def _segments_cross(p1, p2, p3, p4):
    """線分 p1-p2 と p3-p4 が交わるか。"""
    def side(a, b, c):
        return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])
    return (side(p1, p2, p3) * side(p1, p2, p4) < 0) and (side(p3, p4, p1) * side(p3, p4, p2) < 0)


def _spring(names, edges, seed):
    """線をばね、丸どうしを反発する磁石とみなして、少しずつ動かして並べる。"""
    import random
    rng = random.Random(seed)
    p = {n: [rng.random(), rng.random()] for n in names}
    k = 1.6 / math.sqrt(len(names))
    for it in range(300):
        move = {n: [0.0, 0.0] for n in names}
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                dx, dy = p[a][0] - p[b][0], p[a][1] - p[b][1]
                d = math.hypot(dx, dy) or 0.01
                f = k * k / d
                move[a][0] += dx / d * f
                move[a][1] += dy / d * f
                move[b][0] -= dx / d * f
                move[b][1] -= dy / d * f
        for a, b, _ in edges:
            dx, dy = p[a][0] - p[b][0], p[a][1] - p[b][1]
            d = math.hypot(dx, dy) or 0.01
            f = d * d / k
            move[a][0] -= dx / d * f
            move[a][1] -= dy / d * f
            move[b][0] += dx / d * f
            move[b][1] += dy / d * f
        heat = 0.1 * (1 - it / 300)
        for n in names:
            d = math.hypot(*move[n]) or 0.01
            p[n][0] += move[n][0] / d * min(d, heat)
            p[n][1] += move[n][1] / d * min(d, heat)
    return p


def _placed(names, edges, where, cx=265, cy=326, radius=196):
    """where = {場所: (横, 縦)}（0〜100）で決めた位置に置く。where にない場所は、つながっている場所の近くに置く。"""
    r = _node_radius(names)
    left, right = 30 + r, 530 - r
    top, bottom = 100 + r * 0.4, HEIGHT - 52 - r
    pos = {n: [left + (right - left) * where[n][0] / 100, top + (bottom - top) * where[n][1] / 100]
           for n in names if n in where}
    fixed = set(pos)
    for _ in range(len(names)):
        for i, n in enumerate(names):
            if n in pos:
                continue
            near = [pos[b if a == n else a] for a, b, _ in edges if n in (a, b) and (b if a == n else a) in pos]
            if near or not pos:
                bx = sum(p[0] for p in near) / len(near) if near else cx
                by = sum(p[1] for p in near) / len(near) if near else cy
                best = None                 # まわり16方向のうち、ほかの丸からいちばん離れた所を選ぶ
                for k in range(16):
                    for dist in (2.6 * r, 3.6 * r):
                        c = (min(max(bx + math.cos(k * math.pi / 8) * dist, left), right),
                             min(max(by + math.sin(k * math.pi / 8) * dist, top), bottom))
                        room = min((math.hypot(c[0] - q[0], c[1] - q[1]) for q in pos.values()), default=9999)
                        if best is None or room > best[0] + 0.5:
                            best = (room, c)
                pos[n] = list(best[1])
    for i, n in enumerate(names):                   # どこともつながっていない場所は、左下に並べる
        if n not in pos:
            pos[n] = [left + i * 2.2 * r % (right - left), bottom]
    gap = 2 * r + 30
    for _ in range(200):
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                dx, dy = pos[a][0] - pos[b][0], pos[a][1] - pos[b][1]
                d = math.hypot(dx, dy) or 0.01
                if d < gap:
                    for n, sign in ((a, 1), (b, -1)):
                        if n not in fixed:
                            share = 1 if (a in fixed or b in fixed) else 0.5
                            pos[n][0] += sign * dx / d * (gap - d) * share
                            pos[n][1] += sign * dy / d * (gap - d) * share
        for n in names:
            pos[n][0] = min(max(pos[n][0], left), right)
            pos[n][1] = min(max(pos[n][1], top), bottom)
    return {n: tuple(v) for n, v in pos.items()}


def _layout(names, edges, cx=265, cy=326, radius=196):
    """頂点の位置を決める。
    8個以下: 円の上に等間隔で並べ、線の交わりがいちばん少なくなる順番を全部試して選ぶ。
    9個以上: ばねのしくみで並べ、線の交わりがいちばん少ないものを選ぶ。"""
    order = list(names)
    n = len(order)
    if n <= 8:
        if n > 3:
            from itertools import permutations
            best = None
            for rest in permutations(order[1:]):
                cand = [order[0], *rest]
                k = _crossings(cand, edges)
                if best is None or k < best[0]:
                    best = (k, cand)
            order = best[1]
        return {name: (cx + radius * math.sin(2 * math.pi * i / n), cy - radius * math.cos(2 * math.pi * i / n))
                for i, name in enumerate(order)}
    best = None
    for seed in range(12):
        p = _spring(order, edges, seed)
        k = sum(_segments_cross(p[a], p[b], p[c], p[d])
                for i, (a, b, _) in enumerate(edges) for c, d, _ in edges[i + 1:] if len({a, b, c, d}) == 4)
        if best is None or k < best[0]:
            best = (k, p)
    p = best[1]
    xs, ys = [v[0] for v in p.values()], [v[1] for v in p.values()]
    w, h = (max(xs) - min(xs)) or 1, (max(ys) - min(ys)) or 1
    pos = {name: [cx - radius * 1.12 + (p[name][0] - min(xs)) / w * radius * 2.24,
                  cy - radius + (p[name][1] - min(ys)) / h * radius * 2] for name in order}
    gap = 2 * _node_radius(order) + 46          # 丸どうしが近すぎるときは押し広げる
    for _ in range(200):
        for i, a in enumerate(order):
            for b in order[i + 1:]:
                dx, dy = pos[a][0] - pos[b][0], pos[a][1] - pos[b][1]
                d = math.hypot(dx, dy) or 0.01
                if d < gap:
                    push = (gap - d) / 2
                    pos[a][0] += dx / d * push
                    pos[a][1] += dy / d * push
                    pos[b][0] -= dx / d * push
                    pos[b][1] -= dy / d * push
        for name in order:
            pos[name][0] = min(max(pos[name][0], cx - radius * 1.12), cx + radius * 1.12)
            pos[name][1] = min(max(pos[name][1], cy - radius), cy + radius)
    return {name: tuple(v) for name, v in pos.items()}


def _node_radius(names):

def _near_segment(c, p, q):
    """点 c と線分 p-q のいちばん近いところまでの長さ。"""
    dx, dy = q[0] - p[0], q[1] - p[1]
    t = max(0, min(1, ((c[0] - p[0]) * dx + (c[1] - p[1]) * dy) / ((dx * dx + dy * dy) or 1)))
    return math.hypot(c[0] - p[0] - t * dx, c[1] - p[1] - t * dy)


def _label_spots(names, edges, pos, r):
    """丸の外に書く数字の位置を、丸の周り8方向から、線や他の丸とぶつからないところを選んで決める。"""
    spots = {}
    for name in names:
        x, y = pos[name]
        best = None
        for i in range(8):
            ang = math.pi / 2 + i * math.pi / 4          # 真下から順に試す
            c = (x + math.cos(ang) * (r + 24), y + math.sin(ang) * (r + 14))
            cost = i * 0.01
            if not (32 < c[0] < 525 and 78 < c[1] < HEIGHT - 44):
                cost += 100
            for other in names:
                if other != name:
                    cost += max(0, 2 * r + 10 - math.hypot(c[0] - pos[other][0], c[1] - pos[other][1]))
            for a, b, _ in edges:
                cost += max(0, 22 - _near_segment(c, pos[a], pos[b])) * 2
                mid = ((pos[a][0] + pos[b][0]) / 2, (pos[a][1] + pos[b][1]) / 2)
                cost += max(0, 44 - math.hypot(c[0] - mid[0], c[1] - mid[1])) * 2
            for sx, sy in spots.values():
                cost += max(0, 50 - math.hypot(c[0] - sx, c[1] - sy)) * 2
            if best is None or cost < best[0]:
                best = (cost, c)
        spots[name] = best[1]
    return spots


def _split_at(name):
    """2行に分ける位置を決める。「ー」や小さい字で始まる行を作らず、「ー」の後ろや漢字の前で切ると読みやすい。"""
    def score(i):
        s = abs(i - len(name) / 2)
        if name[i - 1] in "ー・ ":
            s -= 1.5
        if ("\u4e00" <= name[i] <= "\u9fff") != ("\u4e00" <= name[i - 1] <= "\u9fff"):
            s -= len(name)
        return (s, -i)
    spots = [i for i in range(1, len(name)) if name[i] not in "ーァィゥェォッャュョヮンぁぃぅぇぉっゃゅょん、。）」"]
    return min(spots, key=score) if spots else (len(name) + 1) // 2


def _shrink(t, width):
    """t（文字の絵）が width より広ければ、width に収まるように縮める。"""
    if t.get_width() <= width:
        return t
    k = width / t.get_width()
    return pygame.transform.smoothscale(t, (int(t.get_width() * k), int(t.get_height() * k)))


def _name_in_circle(screen, fonts, name, x, y, r):
    """丸の中に名前を書く。長い名前は小さい文字にし、それでも長ければ2行に分ける。"""
    _, mid, small = fonts
    t = mid.render(name, True, TEXT)
    if t.get_width() > 2 * r - 6:
        t = small.render(name, True, TEXT)
    if t.get_width() > 2 * r - 6:
        half = _split_at(name)
        t1, t2 = small.render(name[:half], True, TEXT), small.render(name[half:].lstrip("・ "), True, TEXT)
        t1, t2 = _shrink(t1, 2 * r - 4), _shrink(t2, 2 * r - 4)     # それでも丸からはみ出す行は、文字を縮める
        screen.blit(t1, (x - t1.get_width() / 2, y - t1.get_height()))
        screen.blit(t2, (x - t2.get_width() / 2, y))
        return
    screen.blit(t, (x - t.get_width() / 2, y - t.get_height() / 2))


def _dashed(screen, color, p, q, dash=10):
    """p から q へ点線を引く。"""
    length = math.hypot(q[0] - p[0], q[1] - p[1]) or 1
    for i in range(0, int(length), dash * 2):
        a, b = i / length, min(i + dash, length) / length
        pygame.draw.line(screen, color, (p[0] + (q[0] - p[0]) * a, p[1] + (q[1] - p[1]) * a),
                         (p[0] + (q[0] - p[0]) * b, p[1] + (q[1] - p[1]) * b), 3)


def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"


def _minutes(v):

def _loop(screen, fonts, last_step, draw):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = last_step if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False
        screen.fill(BG)
        draw(k)
        hint = fonts[2].render("スペース: 再生／一時停止   →: 1手順すすめる   R: 最初から   Esc: 終わる", True, SUB)
        screen.blit(hint, (30, HEIGHT - 30))
        pygame.display.flip()
        if capture:
            pygame.image.save(screen, capture)
            pygame.quit()
            return
        clock.tick(30)

            ty = y + (row_h - 4 - font.get_height()) // 2

        screen.blit(small.render("緑 = 確定した場所　橙 = この手順で書き込み・書き直した時間", True, SUB), (x0, 52))
        table(dist, settled, None if final else current, [] if final else changes)
        by = 114 + len(names) * row_h + 16
        lines = []

            lines = [(f"はじめ: {start} だけ 0分、ほかは「－」（inf）", TEXT), ("スペースで開始／→で1手順", SUB)]

def _graph_parts(graph):
    """隣接リストから、丸にする場所の名前と、線（場所, 場所, 時間）の一覧を作る。"""
    names = list(graph)
    for a in graph:
        for b, _ in graph[a]:
            if b not in names:
                names.append(b)
    edges = []
    for a in graph:
        for b, w in graph[a]:
            if not any({a, b} == {x, y} for x, y, _ in edges):

    return names, edges


def _weight(graph, a, b):
    """a から b への時間。直接つながっていなければ None。"""
    for name, w in graph.get(a, []):

            return w
    return None


def _problems(graph, names, final_distance):
    """地図の書きまちがいを、赤い字で知らせる文の一覧にする。"""
    out = []

def _crossings(order, edges):
    """円の上に order の順で頂点を並べたとき、線どうしが何回交わるかを数える。"""
    at = {name: i for i, name in enumerate(order)}
    count = 0
    for i, (a, b, _) in enumerate(edges):
        lo, hi = sorted((at[a], at[b]))
        for c, d, _ in edges[i + 1:]:
            if len({a, b, c, d}) < 4:
                continue
            inside = (lo < at[c] < hi) + (lo < at[d] < hi)
            count += inside == 1
    return count


def _segments_cross(p1, p2, p3, p4):
    """線分 p1-p2 と p3-p4 が交わるか。"""
    def side(a, b, c):
        return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])
    return (side(p1, p2, p3) * side(p1, p2, p4) < 0) and (side(p3, p4, p1) * side(p3, p4, p2) < 0)


def _spring(names, edges, seed):
    """線をばね、丸どうしを反発する磁石とみなして、少しずつ動かして並べる。"""
    import random
    rng = random.Random(seed)
    p = {n: [rng.random(), rng.random()] for n in names}
    k = 1.6 / math.sqrt(len(names))
    for it in range(300):
        move = {n: [0.0, 0.0] for n in names}
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                dx, dy = p[a][0] - p[b][0], p[a][1] - p[b][1]
                d = math.hypot(dx, dy) or 0.01
                f = k * k / d
                move[a][0] += dx / d * f
                move[a][1] += dy / d * f
                move[b][0] -= dx / d * f
                move[b][1] -= dy / d * f
        for a, b, _ in edges:
            dx, dy = p[a][0] - p[b][0], p[a][1] - p[b][1]
            d = math.hypot(dx, dy) or 0.01
            f = d * d / k
            move[a][0] -= dx / d * f
            move[a][1] -= dy / d * f
            move[b][0] += dx / d * f
            move[b][1] += dy / d * f
        heat = 0.1 * (1 - it / 300)
        for n in names:
            d = math.hypot(*move[n]) or 0.01
            p[n][0] += move[n][0] / d * min(d, heat)
            p[n][1] += move[n][1] / d * min(d, heat)
    return p


def _placed(names, edges, where, cx=265, cy=326, radius=196):
    """where = {場所: (横, 縦)}（0〜100）で決めた位置に置く。where にない場所は、つながっている場所の近くに置く。"""
    r = _node_radius(names)
    left, right = 30 + r, 530 - r
    top, bottom = 100 + r * 0.4, HEIGHT - 52 - r
    pos = {n: [left + (right - left) * where[n][0] / 100, top + (bottom - top) * where[n][1] / 100]
           for n in names if n in where}
    fixed = set(pos)
    for _ in range(len(names)):
        for i, n in enumerate(names):
            if n in pos:
                continue
            near = [pos[b if a == n else a] for a, b, _ in edges if n in (a, b) and (b if a == n else a) in pos]
            if near or not pos:
                bx = sum(p[0] for p in near) / len(near) if near else cx
                by = sum(p[1] for p in near) / len(near) if near else cy
                best = None                 # まわり16方向のうち、ほかの丸からいちばん離れた所を選ぶ
                for k in range(16):
                    for dist in (2.6 * r, 3.6 * r):
                        c = (min(max(bx + math.cos(k * math.pi / 8) * dist, left), right),
                             min(max(by + math.sin(k * math.pi / 8) * dist, top), bottom))
                        room = min((math.hypot(c[0] - q[0], c[1] - q[1]) for q in pos.values()), default=9999)
                        if best is None or room > best[0] + 0.5:
                            best = (room, c)
                pos[n] = list(best[1])
    for i, n in enumerate(names):                   # どこともつながっていない場所は、左下に並べる
        if n not in pos:
            pos[n] = [left + i * 2.2 * r % (right - left), bottom]
    gap = 2 * r + 30
    for _ in range(200):
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                dx, dy = pos[a][0] - pos[b][0], pos[a][1] - pos[b][1]
                d = math.hypot(dx, dy) or 0.01
                if d < gap:
                    for n, sign in ((a, 1), (b, -1)):
                        if n not in fixed:
                            share = 1 if (a in fixed or b in fixed) else 0.5
                            pos[n][0] += sign * dx / d * (gap - d) * share
                            pos[n][1] += sign * dy / d * (gap - d) * share
        for n in names:
            pos[n][0] = min(max(pos[n][0], left), right)
            pos[n][1] = min(max(pos[n][1], top), bottom)
    return {n: tuple(v) for n, v in pos.items()}


def _layout(names, edges, cx=265, cy=326, radius=196):
    """頂点の位置を決める。
    8個以下: 円の上に等間隔で並べ、線の交わりがいちばん少なくなる順番を全部試して選ぶ。
    9個以上: ばねのしくみで並べ、線の交わりがいちばん少ないものを選ぶ。"""
    order = list(names)
    n = len(order)
    if n <= 8:
        if n > 3:
            from itertools import permutations
            best = None
            for rest in permutations(order[1:]):
                cand = [order[0], *rest]
                k = _crossings(cand, edges)
                if best is None or k < best[0]:
                    best = (k, cand)
            order = best[1]
        return {name: (cx + radius * math.sin(2 * math.pi * i / n), cy - radius * math.cos(2 * math.pi * i / n))
                for i, name in enumerate(order)}
    best = None
    for seed in range(12):
        p = _spring(order, edges, seed)
        k = sum(_segments_cross(p[a], p[b], p[c], p[d])
                for i, (a, b, _) in enumerate(edges) for c, d, _ in edges[i + 1:] if len({a, b, c, d}) == 4)
        if best is None or k < best[0]:
            best = (k, p)
    p = best[1]
    xs, ys = [v[0] for v in p.values()], [v[1] for v in p.values()]
    w, h = (max(xs) - min(xs)) or 1, (max(ys) - min(ys)) or 1
    pos = {name: [cx - radius * 1.12 + (p[name][0] - min(xs)) / w * radius * 2.24,
                  cy - radius + (p[name][1] - min(ys)) / h * radius * 2] for name in order}
    gap = 2 * _node_radius(order) + 46          # 丸どうしが近すぎるときは押し広げる
    for _ in range(200):
        for i, a in enumerate(order):
            for b in order[i + 1:]:
                dx, dy = pos[a][0] - pos[b][0], pos[a][1] - pos[b][1]
                d = math.hypot(dx, dy) or 0.01
                if d < gap:
                    push = (gap - d) / 2
                    pos[a][0] += dx / d * push
                    pos[a][1] += dy / d * push
                    pos[b][0] -= dx / d * push
                    pos[b][1] -= dy / d * push
        for name in order:
            pos[name][0] = min(max(pos[name][0], cx - radius * 1.12), cx + radius * 1.12)
            pos[name][1] = min(max(pos[name][1], cy - radius), cy + radius)
    return {name: tuple(v) for name, v in pos.items()}


def _node_radius(names):
    return 38 if len(names) <= 10 else (34 if len(names) <= 12 else 28)


def _draw_graph(screen, fonts, names, edges, pos, colored=(), rings=None, labels=None, closed=()):

    edge_color = {}
    shut = {frozenset(p) for p in closed}
    for a, b, _ in edges:
        if frozenset((a, b)) in shut:

    for a, b, w in edges:
        mx, my = (pos[a][0] + pos[b][0]) / 2, (pos[a][1] + pos[b][1]) / 2

def _near_segment(c, p, q):
    """点 c と線分 p-q のいちばん近いところまでの長さ。"""
    dx, dy = q[0] - p[0], q[1] - p[1]
    t = max(0, min(1, ((c[0] - p[0]) * dx + (c[1] - p[1]) * dy) / ((dx * dx + dy * dy) or 1)))
    return math.hypot(c[0] - p[0] - t * dx, c[1] - p[1] - t * dy)


def _label_spots(names, edges, pos, r):
    """丸の外に書く数字の位置を、丸の周り8方向から、線や他の丸とぶつからないところを選んで決める。"""
    spots = {}
    for name in names:
        x, y = pos[name]
        best = None
        for i in range(8):
            ang = math.pi / 2 + i * math.pi / 4          # 真下から順に試す
            c = (x + math.cos(ang) * (r + 24), y + math.sin(ang) * (r + 14))
            cost = i * 0.01
            if not (32 < c[0] < 525 and 78 < c[1] < HEIGHT - 44):
                cost += 100
            for other in names:
                if other != name:
                    cost += max(0, 2 * r + 10 - math.hypot(c[0] - pos[other][0], c[1] - pos[other][1]))
            for a, b, _ in edges:
                cost += max(0, 22 - _near_segment(c, pos[a], pos[b])) * 2
                mid = ((pos[a][0] + pos[b][0]) / 2, (pos[a][1] + pos[b][1]) / 2)
                cost += max(0, 44 - math.hypot(c[0] - mid[0], c[1] - mid[1])) * 2
            for sx, sy in spots.values():
                cost += max(0, 50 - math.hypot(c[0] - sx, c[1] - sy)) * 2
            if best is None or cost < best[0]:
                best = (cost, c)
        spots[name] = best[1]
    return spots


def _split_at(name):
    """2行に分ける位置を決める。「ー」や小さい字で始まる行を作らず、「ー」の後ろや漢字の前で切ると読みやすい。"""
    def score(i):
        s = abs(i - len(name) / 2)
        if name[i - 1] in "ー・ ":
            s -= 1.5
        if ("\u4e00" <= name[i] <= "\u9fff") != ("\u4e00" <= name[i - 1] <= "\u9fff"):
            s -= len(name)
        return (s, -i)
    spots = [i for i in range(1, len(name)) if name[i] not in "ーァィゥェォッャュョヮンぁぃぅぇぉっゃゅょん、。）」"]
    return min(spots, key=score) if spots else (len(name) + 1) // 2


def _shrink(t, width):
    """t（文字の絵）が width より広ければ、width に収まるように縮める。"""
    if t.get_width() <= width:
        return t
    k = width / t.get_width()
    return pygame.transform.smoothscale(t, (int(t.get_width() * k), int(t.get_height() * k)))


def _name_in_circle(screen, fonts, name, x, y, r):
    """丸の中に名前を書く。長い名前は小さい文字にし、それでも長ければ2行に分ける。"""
    _, mid, small = fonts
    t = mid.render(name, True, TEXT)
    if t.get_width() > 2 * r - 6:
        t = small.render(name, True, TEXT)
    if t.get_width() > 2 * r - 6:
        half = _split_at(name)
        t1, t2 = small.render(name[:half], True, TEXT), small.render(name[half:].lstrip("・ "), True, TEXT)
        t1, t2 = _shrink(t1, 2 * r - 4), _shrink(t2, 2 * r - 4)     # それでも丸からはみ出す行は、文字を縮める
        screen.blit(t1, (x - t1.get_width() / 2, y - t1.get_height()))
        screen.blit(t2, (x - t2.get_width() / 2, y))
        return
    screen.blit(t, (x - t.get_width() / 2, y - t.get_height() / 2))


def _dashed(screen, color, p, q, dash=10):
    """p から q へ点線を引く。"""
    length = math.hypot(q[0] - p[0], q[1] - p[1]) or 1
    for i in range(0, int(length), dash * 2):
        a, b = i / length, min(i + dash, length) / length
        pygame.draw.line(screen, color, (p[0] + (q[0] - p[0]) * a, p[1] + (q[1] - p[1]) * a),
                         (p[0] + (q[0] - p[0]) * b, p[1] + (q[1] - p[1]) * b), 3)


def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"

def _loop(screen, fonts, last_step, draw):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = last_step if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False
        screen.fill(BG)
        draw(k)
        hint = fonts[2].render("スペース: 再生／一時停止   →: 1手順すすめる   R: 最初から   Esc: 終わる", True, SUB)
        screen.blit(hint, (30, HEIGHT - 30))
        pygame.display.flip()
        if capture:
            pygame.image.save(screen, capture)
            pygame.quit()
            return
        clock.tick(30)

def dijkstra(start):
    """start から各駅までの最短時間 distance と、来た駅の記録 came_from を求める（例題1と同じ手順）。
    地図は、上で作った railway を使う。"""
    distance = {}
    came_from = {}                  # 鍵 = 駅、値 = その駅へいちばん早く来るときの、1つ前の駅
    for station in railway:
        distance[station] = INF
        came_from[station] = None   # None は「まだ分からない」（出発点は最後まで None のまま）
    distance[start] = 0
    settled = set()
    log = [(None, dict(distance), set(settled), dict(came_from))]   # 手順ごとの記録（窓の表示に使う）
    while len(settled) < len(railway):
        current = None
        for station in railway:
            if station in settled or distance[station] == INF:
                continue
            if current is None or distance[station] < distance[current]:
                current = station
        if current is None:
            break
        settled.add(current)
        for name, minutes in railway[current]:     # name = となりの駅
            if name in settled:
                continue
            new_distance = distance[current] + minutes
            if new_distance < distance[name]:
                distance[name] = new_distance
                came_from[name] = current       # 時間を書き直すときに、「current から来た」も書き直す
        log.append((current, dict(distance), set(settled), dict(came_from)))
    return distance, came_from, log


def build_route(goal, came_from):
    """ゴールから came_from を逆にたどって、道順（駅の並び）を作る。"""
    route = []
    node = goal
    while node is not None:         # 出発点の came_from は None なので、そこで止まる
        route.append(node)
        node = came_from[node]      # 1つ前の駅へもどる
    route.reverse()                 # ゴール → 出発点 の順を、出発点 → ゴール の順にひっくり返す
    return route

def _graph_parts(graph):
    """隣接リストから、丸にする場所の名前と、線（場所, 場所, 時間）の一覧を作る。"""
    names = list(graph)
    for a in graph:
        for b, _ in graph[a]:
            if b not in names:
                names.append(b)
    edges = []
    for a in graph:
        for b, w in graph[a]:
            if not any({a, b} == {x, y} for x, y, _ in edges):
                edges.append((a, b, w))
    return names, edges


def _weight(graph, a, b):
    """a から b への時間。直接つながっていなければ None。"""
    for name, w in graph.get(a, []):
        if name == b:
            return w
    return None


def _problems(graph, names, final_distance):
    """地図の書きまちがいを、赤い字で知らせる文の一覧にする。"""
    out = []
    for a in graph:
        for b, w in graph[a]:
            if w < 0:
                out.append(f"{a}—{b} がマイナス（{w}分）。正しく動かない")
            back = _weight(graph, b, a)
            if back is None:
                out.append(f"{b} の行に {a} がない（道は両方の行に書く）")
            elif back != w and names.index(a) < names.index(b):
                out.append(f"{a}—{b}: 行き{w}分・帰り{back}分（そろえる）")
    for name in names:
        if final_distance.get(name, INF) == INF:
            out.append(f"{name} へは行けない（道がつながっていない）")
    return out


def _crossings(order, edges):
    """円の上に order の順で頂点を並べたとき、線どうしが何回交わるかを数える。"""
    at = {name: i for i, name in enumerate(order)}
    count = 0
    for i, (a, b, _) in enumerate(edges):
        lo, hi = sorted((at[a], at[b]))
        for c, d, _ in edges[i + 1:]:
            if len({a, b, c, d}) < 4:
                continue
            inside = (lo < at[c] < hi) + (lo < at[d] < hi)
            count += inside == 1
    return count


def _segments_cross(p1, p2, p3, p4):
    """線分 p1-p2 と p3-p4 が交わるか。"""
    def side(a, b, c):
        return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])
    return (side(p1, p2, p3) * side(p1, p2, p4) < 0) and (side(p3, p4, p1) * side(p3, p4, p2) < 0)


def _spring(names, edges, seed):
    """線をばね、丸どうしを反発する磁石とみなして、少しずつ動かして並べる。"""
    import random
    rng = random.Random(seed)
    p = {n: [rng.random(), rng.random()] for n in names}
    k = 1.6 / math.sqrt(len(names))
    for it in range(300):
        move = {n: [0.0, 0.0] for n in names}
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                dx, dy = p[a][0] - p[b][0], p[a][1] - p[b][1]
                d = math.hypot(dx, dy) or 0.01
                f = k * k / d
                move[a][0] += dx / d * f
                move[a][1] += dy / d * f
                move[b][0] -= dx / d * f
                move[b][1] -= dy / d * f
        for a, b, _ in edges:
            dx, dy = p[a][0] - p[b][0], p[a][1] - p[b][1]
            d = math.hypot(dx, dy) or 0.01
            f = d * d / k
            move[a][0] -= dx / d * f
            move[a][1] -= dy / d * f
            move[b][0] += dx / d * f
            move[b][1] += dy / d * f
        heat = 0.1 * (1 - it / 300)
        for n in names:
            d = math.hypot(*move[n]) or 0.01
            p[n][0] += move[n][0] / d * min(d, heat)
            p[n][1] += move[n][1] / d * min(d, heat)
    return p


def _placed(names, edges, where, cx=265, cy=326, radius=196):
    """where = {場所: (横, 縦)}（0〜100）で決めた位置に置く。where にない場所は、つながっている場所の近くに置く。"""
    r = _node_radius(names)
    left, right = 30 + r, 530 - r
    top, bottom = 100 + r * 0.4, HEIGHT - 52 - r
    pos = {n: [left + (right - left) * where[n][0] / 100, top + (bottom - top) * where[n][1] / 100]
           for n in names if n in where}
    fixed = set(pos)
    for _ in range(len(names)):
        for i, n in enumerate(names):
            if n in pos:
                continue
            near = [pos[b if a == n else a] for a, b, _ in edges if n in (a, b) and (b if a == n else a) in pos]
            if near or not pos:
                bx = sum(p[0] for p in near) / len(near) if near else cx
                by = sum(p[1] for p in near) / len(near) if near else cy
                best = None                 # まわり16方向のうち、ほかの丸からいちばん離れた所を選ぶ
                for k in range(16):
                    for dist in (2.6 * r, 3.6 * r):
                        c = (min(max(bx + math.cos(k * math.pi / 8) * dist, left), right),
                             min(max(by + math.sin(k * math.pi / 8) * dist, top), bottom))
                        room = min((math.hypot(c[0] - q[0], c[1] - q[1]) for q in pos.values()), default=9999)
                        if best is None or room > best[0] + 0.5:
                            best = (room, c)
                pos[n] = list(best[1])
    for i, n in enumerate(names):                   # どこともつながっていない場所は、左下に並べる
        if n not in pos:
            pos[n] = [left + i * 2.2 * r % (right - left), bottom]
    gap = 2 * r + 30
    for _ in range(200):
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                dx, dy = pos[a][0] - pos[b][0], pos[a][1] - pos[b][1]
                d = math.hypot(dx, dy) or 0.01
                if d < gap:
                    for n, sign in ((a, 1), (b, -1)):
                        if n not in fixed:
                            share = 1 if (a in fixed or b in fixed) else 0.5
                            pos[n][0] += sign * dx / d * (gap - d) * share
                            pos[n][1] += sign * dy / d * (gap - d) * share
        for n in names:
            pos[n][0] = min(max(pos[n][0], left), right)
            pos[n][1] = min(max(pos[n][1], top), bottom)
    return {n: tuple(v) for n, v in pos.items()}


def _layout(names, edges, cx=265, cy=326, radius=196):
    """頂点の位置を決める。
    8個以下: 円の上に等間隔で並べ、線の交わりがいちばん少なくなる順番を全部試して選ぶ。
    9個以上: ばねのしくみで並べ、線の交わりがいちばん少ないものを選ぶ。"""
    order = list(names)
    n = len(order)
    if n <= 8:
        if n > 3:
            from itertools import permutations
            best = None
            for rest in permutations(order[1:]):
                cand = [order[0], *rest]
                k = _crossings(cand, edges)
                if best is None or k < best[0]:
                    best = (k, cand)
            order = best[1]
        return {name: (cx + radius * math.sin(2 * math.pi * i / n), cy - radius * math.cos(2 * math.pi * i / n))
                for i, name in enumerate(order)}
    best = None
    for seed in range(12):
        p = _spring(order, edges, seed)
        k = sum(_segments_cross(p[a], p[b], p[c], p[d])
                for i, (a, b, _) in enumerate(edges) for c, d, _ in edges[i + 1:] if len({a, b, c, d}) == 4)
        if best is None or k < best[0]:
            best = (k, p)
    p = best[1]
    xs, ys = [v[0] for v in p.values()], [v[1] for v in p.values()]
    w, h = (max(xs) - min(xs)) or 1, (max(ys) - min(ys)) or 1
    pos = {name: [cx - radius * 1.12 + (p[name][0] - min(xs)) / w * radius * 2.24,
                  cy - radius + (p[name][1] - min(ys)) / h * radius * 2] for name in order}
    gap = 2 * _node_radius(order) + 46          # 丸どうしが近すぎるときは押し広げる
    for _ in range(200):
        for i, a in enumerate(order):
            for b in order[i + 1:]:
                dx, dy = pos[a][0] - pos[b][0], pos[a][1] - pos[b][1]
                d = math.hypot(dx, dy) or 0.01
                if d < gap:
                    push = (gap - d) / 2
                    pos[a][0] += dx / d * push
                    pos[a][1] += dy / d * push
                    pos[b][0] -= dx / d * push
                    pos[b][1] -= dy / d * push
        for name in order:
            pos[name][0] = min(max(pos[name][0], cx - radius * 1.12), cx + radius * 1.12)
            pos[name][1] = min(max(pos[name][1], cy - radius), cy + radius)
    return {name: tuple(v) for name, v in pos.items()}


def _node_radius(names):
    return 38 if len(names) <= 10 else (34 if len(names) <= 12 else 28)


def _draw_graph(screen, fonts, names, edges, pos, colored=(), rings=None, labels=None, closed=()):
    """丸（頂点）と線（辺）と、線のまん中の重み（時間）を描く。
    colored = [(場所の組の一覧, 色, 太さ), ...]。rings = {場所: 枠の色}。
    labels = {場所: (文字, 色)} は丸の外側に書く（距離表の値）。closed は通れない道（赤い点線）。"""
    big, mid, small = fonts
    r = _node_radius(names)
    edge_color = {}
    shut = {frozenset(p) for p in closed}
    for a, b, _ in edges:
        if frozenset((a, b)) in shut:
            _dashed(screen, RED, pos[a], pos[b])
        else:
            pygame.draw.line(screen, LINE, pos[a], pos[b], 2)
    for pairs, color, width in colored:
        for a, b in pairs:
            if a in pos and b in pos:
                pygame.draw.line(screen, color, pos[a], pos[b], width)
                edge_color[frozenset((a, b))] = color
    for a, b, w in edges:
        mx, my = (pos[a][0] + pos[b][0]) / 2, (pos[a][1] + pos[b][1]) / 2
        key = frozenset((a, b))
        color = RED if key in shut else edge_color.get(key, TEXT)
        t = small.render("通行止め" if key in shut else f"{w}分", True, color)
        box = pygame.Rect(0, 0, t.get_width() + 12, t.get_height() + 4)
        box.center = (mx, my)
        pygame.draw.rect(screen, BG, box, border_radius=8)
        pygame.draw.rect(screen, color if key in edge_color or key in shut else LINE, box, width=1, border_radius=8)
        screen.blit(t, (box.x + 6, box.y + 2))
    spots = _label_spots(names, edges, pos, r) if labels else {}
    for name in names:
        x, y = pos[name]
        ring = (rings or {}).get(name, LINE)
        pygame.draw.circle(screen, NODE, (x, y), r)
        pygame.draw.circle(screen, ring, (x, y), r, 5 if ring != LINE else 3)
        _name_in_circle(screen, fonts, name, x, y, r)
        if labels and name in labels:
            text, color = labels[name]
            t = mid.render(text, True, color)
            box = pygame.Rect(0, 0, t.get_width() + 8, t.get_height())
            box.center = spots[name]
            pygame.draw.rect(screen, BG, box, border_radius=6)
            screen.blit(t, (box.x + 4, box.y))


def _near_segment(c, p, q):
    """点 c と線分 p-q のいちばん近いところまでの長さ。"""
    dx, dy = q[0] - p[0], q[1] - p[1]
    t = max(0, min(1, ((c[0] - p[0]) * dx + (c[1] - p[1]) * dy) / ((dx * dx + dy * dy) or 1)))
    return math.hypot(c[0] - p[0] - t * dx, c[1] - p[1] - t * dy)


def _label_spots(names, edges, pos, r):
    """丸の外に書く数字の位置を、丸の周り8方向から、線や他の丸とぶつからないところを選んで決める。"""
    spots = {}
    for name in names:
        x, y = pos[name]
        best = None
        for i in range(8):
            ang = math.pi / 2 + i * math.pi / 4          # 真下から順に試す
            c = (x + math.cos(ang) * (r + 24), y + math.sin(ang) * (r + 14))
            cost = i * 0.01
            if not (32 < c[0] < 525 and 78 < c[1] < HEIGHT - 44):
                cost += 100
            for other in names:
                if other != name:
                    cost += max(0, 2 * r + 10 - math.hypot(c[0] - pos[other][0], c[1] - pos[other][1]))
            for a, b, _ in edges:
                cost += max(0, 22 - _near_segment(c, pos[a], pos[b])) * 2
                mid = ((pos[a][0] + pos[b][0]) / 2, (pos[a][1] + pos[b][1]) / 2)
                cost += max(0, 44 - math.hypot(c[0] - mid[0], c[1] - mid[1])) * 2
            for sx, sy in spots.values():
                cost += max(0, 50 - math.hypot(c[0] - sx, c[1] - sy)) * 2
            if best is None or cost < best[0]:
                best = (cost, c)
        spots[name] = best[1]
    return spots


def _split_at(name):
    """2行に分ける位置を決める。「ー」や小さい字で始まる行を作らず、「ー」の後ろや漢字の前で切ると読みやすい。"""
    def score(i):
        s = abs(i - len(name) / 2)
        if name[i - 1] in "ー・ ":
            s -= 1.5
        if ("\u4e00" <= name[i] <= "\u9fff") != ("\u4e00" <= name[i - 1] <= "\u9fff"):
            s -= len(name)
        return (s, -i)
    spots = [i for i in range(1, len(name)) if name[i] not in "ーァィゥェォッャュョヮンぁぃぅぇぉっゃゅょん、。）」"]
    return min(spots, key=score) if spots else (len(name) + 1) // 2


def _shrink(t, width):
    """t（文字の絵）が width より広ければ、width に収まるように縮める。"""
    if t.get_width() <= width:
        return t
    k = width / t.get_width()
    return pygame.transform.smoothscale(t, (int(t.get_width() * k), int(t.get_height() * k)))


def _name_in_circle(screen, fonts, name, x, y, r):
    """丸の中に名前を書く。長い名前は小さい文字にし、それでも長ければ2行に分ける。"""
    _, mid, small = fonts
    t = mid.render(name, True, TEXT)
    if t.get_width() > 2 * r - 6:
        t = small.render(name, True, TEXT)
    if t.get_width() > 2 * r - 6:
        half = _split_at(name)
        t1, t2 = small.render(name[:half], True, TEXT), small.render(name[half:].lstrip("・ "), True, TEXT)
        t1, t2 = _shrink(t1, 2 * r - 4), _shrink(t2, 2 * r - 4)     # それでも丸からはみ出す行は、文字を縮める
        screen.blit(t1, (x - t1.get_width() / 2, y - t1.get_height()))
        screen.blit(t2, (x - t2.get_width() / 2, y))
        return
    screen.blit(t, (x - t.get_width() / 2, y - t.get_height() / 2))


def _dashed(screen, color, p, q, dash=10):
    """p から q へ点線を引く。"""
    length = math.hypot(q[0] - p[0], q[1] - p[1]) or 1
    for i in range(0, int(length), dash * 2):
        a, b = i / length, min(i + dash, length) / length
        pygame.draw.line(screen, color, (p[0] + (q[0] - p[0]) * a, p[1] + (q[1] - p[1]) * a),
                         (p[0] + (q[0] - p[0]) * b, p[1] + (q[1] - p[1]) * b), 3)


def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"


def _wrap(font, text, width):
    """「 → 」の区切りで、width ピクセルに収まるように何行かに分ける。"""
    out, line = [], ""
    for part in text.split(" → "):
        cand = part if not line else line + " → " + part
        if line and font.size(cand)[0] > width:
            out.append(line + " →")
            line = part
        else:
            line = cand
    return out + [line]


def _minutes(v):
    return "－" if v == INF else f"{v}分"


def _loop(screen, fonts, last_step, draw):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = last_step if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False
        screen.fill(BG)
        draw(k)
        hint = fonts[2].render("スペース: 再生／一時停止   →: 1手順すすめる   R: 最初から   Esc: 終わる", True, SUB)
        screen.blit(hint, (30, HEIGHT - 30))
        pygame.display.flip()
        if capture:
            pygame.image.save(screen, capture)
            pygame.quit()
            return
        clock.tick(30)


def show_window(graph, legs, title, closed=(), where=None):
    """ダイクストラ法で came_from が書かれていくようすと、ゴールから逆にたどって道順を組み立てるようすを表示する。
    legs = [(出発, ゴール, 手順の記録, 道順), ...]。窓を閉じると終わる。"""
    pygame.init()
    screen = pygame.display.set_mode((WIDTH, HEIGHT))
    pygame.display.set_caption(title)
    fonts = (_font(22, True), _font(18), _font(14))
    big, mid, small = fonts
    names, edges = _graph_parts(graph)
    pos = _placed(names, edges, where) if where else _layout(names, edges)
    colors = [GREEN, AMBER, BLUE, (255, 120, 200), (180, 140, 255)]
    frames = [("start", 0, 0)]
    for li, (_, _, log, route) in enumerate(legs):
        frames += [("search", li, j) for j in range(1, len(log))]
        frames += [("back", li, i) for i in range(1, len(route) + 1)]
    frames.append(("end", 0, 0))
    problems = _problems(graph, names, {n: 0 for n in names})
    row_h = max(22, min(36, (HEIGHT - 300) // max(len(names), 1)))
    x0 = 560

    def table(dist, came, settled, current, changed):
        font = mid if row_h >= 30 else small
        screen.blit(small.render("場所", True, SUB), (x0 + 10, 90))
        screen.blit(small.render("時間", True, SUB), (x0 + 190, 90))
        screen.blit(small.render("came_from（1つ前の場所）", True, SUB), (x0 + 270, 90))
        for i, name in enumerate(names):
            y = 114 + i * row_h
            box = pygame.Rect(x0, y, 460, row_h - 4)
            pygame.draw.rect(screen, (26, 44, 10) if name in settled else (30, 30, 38), box, border_radius=6)
            if name == current:
                pygame.draw.rect(screen, WHITE, box, width=3, border_radius=6)
            ty = y + (row_h - 4 - font.get_height()) // 2
            hot = AMBER if name in changed else None
            screen.blit(font.render(_fit(font, name, 170), True, TEXT), (x0 + 10, ty))
            screen.blit(font.render(_minutes(dist.get(name, INF)), True, hot or (GREEN if name in settled else TEXT)), (x0 + 190, ty))
            screen.blit(font.render(_fit(font, str(came.get(name) or "－"), 180), True, hot or TEXT), (x0 + 270, ty))

    def info(lines):
        by = 114 + len(names) * row_h + 16
        room = max(1, (HEIGHT - 40 - by) // 28)
        if len(lines) > room:
            lines = lines[:room - 1] + [(f"ほか {len(lines) - room + 1} 件", SUB)]
        for i, (text, color) in enumerate(lines):
            screen.blit(mid.render(_fit(mid, text, 480), True, color), (x0, by + i * 28))

    def draw(k):
        kind, li, j = frames[k]
        colored, rings, labels, lines = [], {}, None, []
        head, sub = "道順を組み立てる", ""
        if kind == "start" and not legs:

def _crossings(order, edges):
    """円の上に order の順で頂点を並べたとき、線どうしが何回交わるかを数える。"""
    at = {name: i for i, name in enumerate(order)}
    count = 0
    for i, (a, b, _) in enumerate(edges):
        lo, hi = sorted((at[a], at[b]))
        for c, d, _ in edges[i + 1:]:
            if len({a, b, c, d}) < 4:
                continue
            inside = (lo < at[c] < hi) + (lo < at[d] < hi)
            count += inside == 1
    return count


def _segments_cross(p1, p2, p3, p4):
    """線分 p1-p2 と p3-p4 が交わるか。"""
    def side(a, b, c):
        return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])
    return (side(p1, p2, p3) * side(p1, p2, p4) < 0) and (side(p3, p4, p1) * side(p3, p4, p2) < 0)

    p = {n: [rng.random(), rng.random()] for n in names}
    k = 1.6 / math.sqrt(len(names))
    for it in range(300):
        move = {n: [0.0, 0.0] for n in names}
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                dx, dy = p[a][0] - p[b][0], p[a][1] - p[b][1]
                d = math.hypot(dx, dy) or 0.01
                f = k * k / d
                move[a][0] += dx / d * f
                move[a][1] += dy / d * f
                move[b][0] -= dx / d * f
                move[b][1] -= dy / d * f
        for a, b, _ in edges:
            dx, dy = p[a][0] - p[b][0], p[a][1] - p[b][1]
            d = math.hypot(dx, dy) or 0.01
            f = d * d / k
            move[a][0] -= dx / d * f
            move[a][1] -= dy / d * f
            move[b][0] += dx / d * f
            move[b][1] += dy / d * f
        heat = 0.1 * (1 - it / 300)
        for n in names:
            d = math.hypot(*move[n]) or 0.01
            p[n][0] += move[n][0] / d * min(d, heat)
            p[n][1] += move[n][1] / d * min(d, heat)
    return p


def _placed(names, edges, where, cx=265, cy=326, radius=196):
    """where = {場所: (横, 縦)}（0〜100）で決めた位置に置く。where にない場所は、つながっている場所の近くに置く。"""
    r = _node_radius(names)
    left, right = 30 + r, 530 - r
    top, bottom = 100 + r * 0.4, HEIGHT - 52 - r
    pos = {n: [left + (right - left) * where[n][0] / 100, top + (bottom - top) * where[n][1] / 100]
           for n in names if n in where}
    fixed = set(pos)
    for _ in range(len(names)):
        for i, n in enumerate(names):
            if n in pos:
                continue
            near = [pos[b if a == n else a] for a, b, _ in edges if n in (a, b) and (b if a == n else a) in pos]
            if near or not pos:
                bx = sum(p[0] for p in near) / len(near) if near else cx
                by = sum(p[1] for p in near) / len(near) if near else cy
                best = None                 # まわり16方向のうち、ほかの丸からいちばん離れた所を選ぶ
                for k in range(16):
                    for dist in (2.6 * r, 3.6 * r):
                        c = (min(max(bx + math.cos(k * math.pi / 8) * dist, left), right),
                             min(max(by + math.sin(k * math.pi / 8) * dist, top), bottom))
                        room = min((math.hypot(c[0] - q[0], c[1] - q[1]) for q in pos.values()), default=9999)
                        if best is None or room > best[0] + 0.5:
                            best = (room, c)
                pos[n] = list(best[1])
    for i, n in enumerate(names):                   # どこともつながっていない場所は、左下に並べる
        if n not in pos:
            pos[n] = [left + i * 2.2 * r % (right - left), bottom]
    gap = 2 * r + 30
    for _ in range(200):
        for i, a in enumerate(names):
            for b in names[i + 1:]:
                dx, dy = pos[a][0] - pos[b][0], pos[a][1] - pos[b][1]
                d = math.hypot(dx, dy) or 0.01
                if d < gap:
                    for n, sign in ((a, 1), (b, -1)):
                        if n not in fixed:
                            share = 1 if (a in fixed or b in fixed) else 0.5
                            pos[n][0] += sign * dx / d * (gap - d) * share
                            pos[n][1] += sign * dy / d * (gap - d) * share
        for n in names:
            pos[n][0] = min(max(pos[n][0], left), right)
            pos[n][1] = min(max(pos[n][1], top), bottom)
    return {n: tuple(v) for n, v in pos.items()}


def _layout(names, edges, cx=265, cy=326, radius=196):
    """頂点の位置を決める。
    8個以下: 円の上に等間隔で並べ、線の交わりがいちばん少なくなる順番を全部試して選ぶ。
    9個以上: ばねのしくみで並べ、線の交わりがいちばん少ないものを選ぶ。"""
    order = list(names)
    n = len(order)
    if n <= 8:
        if n > 3:
            from itertools import permutations
            best = None
            for rest in permutations(order[1:]):
                cand = [order[0], *rest]
                k = _crossings(cand, edges)
                if best is None or k < best[0]:
                    best = (k, cand)
            order = best[1]
        return {name: (cx + radius * math.sin(2 * math.pi * i / n), cy - radius * math.cos(2 * math.pi * i / n))
                for i, name in enumerate(order)}
    best = None
    for seed in range(12):
        p = _spring(order, edges, seed)
        k = sum(_segments_cross(p[a], p[b], p[c], p[d])
                for i, (a, b, _) in enumerate(edges) for c, d, _ in edges[i + 1:] if len({a, b, c, d}) == 4)
        if best is None or k < best[0]:
            best = (k, p)
    p = best[1]
    xs, ys = [v[0] for v in p.values()], [v[1] for v in p.values()]
    w, h = (max(xs) - min(xs)) or 1, (max(ys) - min(ys)) or 1
    pos = {name: [cx - radius * 1.12 + (p[name][0] - min(xs)) / w * radius * 2.24,
                  cy - radius + (p[name][1] - min(ys)) / h * radius * 2] for name in order}
    gap = 2 * _node_radius(order) + 46          # 丸どうしが近すぎるときは押し広げる
    for _ in range(200):
        for i, a in enumerate(order):
            for b in order[i + 1:]:
                dx, dy = pos[a][0] - pos[b][0], pos[a][1] - pos[b][1]
                d = math.hypot(dx, dy) or 0.01
                if d < gap:
                    push = (gap - d) / 2
                    pos[a][0] += dx / d * push
                    pos[a][1] += dy / d * push
                    pos[b][0] -= dx / d * push
                    pos[b][1] -= dy / d * push
        for name in order:
            pos[name][0] = min(max(pos[name][0], cx - radius * 1.12), cx + radius * 1.12)
            pos[name][1] = min(max(pos[name][1], cy - radius), cy + radius)
    return {name: tuple(v) for name, v in pos.items()}


def _node_radius(names):
    return 38 if len(names) <= 10 else (34 if len(names) <= 12 else 28)

    for a, b, w in edges:
        mx, my = (pos[a][0] + pos[b][0]) / 2, (pos[a][1] + pos[b][1]) / 2
        key = frozenset((a, b))
        color = RED if key in shut else edge_color.get(key, TEXT)

def _near_segment(c, p, q):
    """点 c と線分 p-q のいちばん近いところまでの長さ。"""
    dx, dy = q[0] - p[0], q[1] - p[1]
    t = max(0, min(1, ((c[0] - p[0]) * dx + (c[1] - p[1]) * dy) / ((dx * dx + dy * dy) or 1)))
    return math.hypot(c[0] - p[0] - t * dx, c[1] - p[1] - t * dy)


def _label_spots(names, edges, pos, r):
    """丸の外に書く数字の位置を、丸の周り8方向から、線や他の丸とぶつからないところを選んで決める。"""
    spots = {}
    for name in names:
        x, y = pos[name]
        best = None
        for i in range(8):
            ang = math.pi / 2 + i * math.pi / 4          # 真下から順に試す
            c = (x + math.cos(ang) * (r + 24), y + math.sin(ang) * (r + 14))
            cost = i * 0.01
            if not (32 < c[0] < 525 and 78 < c[1] < HEIGHT - 44):
                cost += 100
            for other in names:
                if other != name:
                    cost += max(0, 2 * r + 10 - math.hypot(c[0] - pos[other][0], c[1] - pos[other][1]))
            for a, b, _ in edges:
                cost += max(0, 22 - _near_segment(c, pos[a], pos[b])) * 2
                mid = ((pos[a][0] + pos[b][0]) / 2, (pos[a][1] + pos[b][1]) / 2)
                cost += max(0, 44 - math.hypot(c[0] - mid[0], c[1] - mid[1])) * 2
            for sx, sy in spots.values():
                cost += max(0, 50 - math.hypot(c[0] - sx, c[1] - sy)) * 2
            if best is None or cost < best[0]:
                best = (cost, c)
        spots[name] = best[1]
    return spots


def _split_at(name):
    """2行に分ける位置を決める。「ー」や小さい字で始まる行を作らず、「ー」の後ろや漢字の前で切ると読みやすい。"""
    def score(i):
        s = abs(i - len(name) / 2)
        if name[i - 1] in "ー・ ":
            s -= 1.5
        if ("\u4e00" <= name[i] <= "\u9fff") != ("\u4e00" <= name[i - 1] <= "\u9fff"):
            s -= len(name)
        return (s, -i)
    spots = [i for i in range(1, len(name)) if name[i] not in "ーァィゥェォッャュョヮンぁぃぅぇぉっゃゅょん、。）」"]
    return min(spots, key=score) if spots else (len(name) + 1) // 2


def _shrink(t, width):
    """t（文字の絵）が width より広ければ、width に収まるように縮める。"""
    if t.get_width() <= width:
        return t
    k = width / t.get_width()
    return pygame.transform.smoothscale(t, (int(t.get_width() * k), int(t.get_height() * k)))


def _name_in_circle(screen, fonts, name, x, y, r):
    """丸の中に名前を書く。長い名前は小さい文字にし、それでも長ければ2行に分ける。"""
    _, mid, small = fonts
    t = mid.render(name, True, TEXT)
    if t.get_width() > 2 * r - 6:
        t = small.render(name, True, TEXT)
    if t.get_width() > 2 * r - 6:
        half = _split_at(name)
        t1, t2 = small.render(name[:half], True, TEXT), small.render(name[half:].lstrip("・ "), True, TEXT)
        t1, t2 = _shrink(t1, 2 * r - 4), _shrink(t2, 2 * r - 4)     # それでも丸からはみ出す行は、文字を縮める
        screen.blit(t1, (x - t1.get_width() / 2, y - t1.get_height()))
        screen.blit(t2, (x - t2.get_width() / 2, y))
        return
    screen.blit(t, (x - t.get_width() / 2, y - t.get_height() / 2))


def _dashed(screen, color, p, q, dash=10):
    """p から q へ点線を引く。"""
    length = math.hypot(q[0] - p[0], q[1] - p[1]) or 1
    for i in range(0, int(length), dash * 2):
        a, b = i / length, min(i + dash, length) / length
        pygame.draw.line(screen, color, (p[0] + (q[0] - p[0]) * a, p[1] + (q[1] - p[1]) * a),
                         (p[0] + (q[0] - p[0]) * b, p[1] + (q[1] - p[1]) * b), 3)


def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"


def _wrap(font, text, width):
    """「 → 」の区切りで、width ピクセルに収まるように何行かに分ける。"""
    out, line = [], ""
    for part in text.split(" → "):
        cand = part if not line else line + " → " + part
        if line and font.size(cand)[0] > width:
            out.append(line + " →")
            line = part
        else:
            line = cand
    return out + [line]


def _minutes(v):
    return "－" if v == INF else f"{v}分"


def _loop(screen, fonts, last_step, draw):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = last_step if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False
        screen.fill(BG)
        draw(k)
        hint = fonts[2].render("スペース: 再生／一時停止   →: 1手順すすめる   R: 最初から   Esc: 終わる", True, SUB)
        screen.blit(hint, (30, HEIGHT - 30))
        pygame.display.flip()
        if capture:
            pygame.image.save(screen, capture)
            pygame.quit()
            return
        clock.tick(30)
