貪欲法とは

第8回で確かめたとおり、巡回セールスマン問題（すべての地点を1回ずつ回って出発点へ戻る、いちばん短いルートをさがす問題）は、 地点が増えると全探索（すべての順番を試す方法）が使えなくなります。15か所で数時間、20か所では何百年〜千年以上かかる見積もりでした。 そこで発想を変えます。「必ず最短」をあきらめて、「そこそこ短いルートを一瞬で作る」方法を考えます。 いちばん単純な作戦が貪欲法（どんよくほう）です。

ナガシマスパーランド（三重県にある、ジェットコースターで有名な遊園地）に着いた場面を思い浮かべてください。 乗りたいものは10個以上あります。第8回の方法で全部の回り方を調べると、10か所で約36万通り、15か所なら何時間もかかり、調べ終わる前に閉園してしまいます。 実際には、多くの人が「とりあえず、いまいる場所からいちばん近いものに乗る。終わったら、またそこからいちばん近いものへ行く」と決めているはずです。 全部の回り方を頭の中で比べる人はいません。 先のことは考えず、目の前でいちばん良さそうな選択をくり返す考え方が、貪欲法です。 「貪欲」は「よくばり」という意味で、毎回その場でいちばん得なもの（いちばん近い場所）をよくばって取ることから、この名前が付いています。 今回のクリエイティブ演習では、自分が回りたい場所を貪欲法で回り、全探索の答えとどれくらいちがうかを調べます。

貪欲法の手順（最近傍法）

  1. 出発点に立つ
  2. まだ行っていない都市のうち、いまいる場所からいちばん近い都市を選ぶ
  3. そこへ移動する
  4. まだ行っていない都市がある間、2と3をくり返す
  5. 全部回り終えたら出発点へ戻る

「いちばん近い都市へ進む」という選び方から、最近傍法（さいきんぼうほう。「最も近い、となり」という意味）とも呼ばれます。 都市が n 個なら、えらぶ回数は n − 1 回で、そのたびに残りの都市までの距離を比べるだけです。 比べる回数は全部で n × (n − 1) ÷ 2 回なので、8都市なら28回、1000都市でも約50万回で終わります （全探索は、8都市で 7! = 5,040通り、1000都市では宇宙が終わるまでかけても終わりません）。

貪欲法が最短にならない理由

貪欲法は、1歩先だけを見て決めます。「いま近い」都市を選んだせいで、 あとから遠く離れた都市が取り残されることがあります。 取り残された都市へ行くには長い移動が必要になり、その1回で、それまでに節約した分をすべて失ってしまいます。 とくに最後に出発点へ戻る1本は、えらぶことができません。どれだけ遠くても行くしかありません。

目の前だけを見て決めた結果、全体としては良くならないことを局所最適（きょくしょさいてき）と呼びます。 「部分的にはいちばん良い」けれど「全体でいちばん良いとはかぎらない」という意味です。 遊園地でいえば、「近いものから順に乗っていたら、いちばん奥のコースターだけが残り、最後に園内を1往復することになった」という状態です。

近似解という考え方

全探索（第8回）貪欲法（第9回）
答えの質必ず最短（最適解）最短とはかぎらない（近似解）
8都市での結果（上の図）46.953.3（13.6%長い）
調べる数(n−1)! 通りの順番n × (n−1) ÷ 2 回の比べ
20都市何百年もかかる一瞬で終わる

考えられる中で本当にいちばん良い答えを最適解（さいてきかい）、 最適ではないけれど実用的な答えを近似解（きんじかい。「近くて似ている答え」という意味）と呼びます。 配送計画では「1%短いルートを1週間かけて計算する」より 「10%長くても1秒で出す」ほうが役に立つ場面がほとんどです。 遊園地でも、回り方を何時間も計算するより、少し遠回りでもすぐ歩き始めたほうが、たくさん乗れます。

貪欲法のコードの書き方 ── 6つの大事な行

例題1の greedy 関数から、表示のための行を取りのぞくと、次の十数行になります。 table は第8回で作った距離の表（table[i][j] = i番から j番までの距離）、count は都市の数、start は出発点の番号です。 演習1（ナガシマスパーランド）でも、「距離」が「歩く時間（分）」に変わるだけで、まったく同じ書き方をしています。

Python ── 例題1の貪欲法の部分（表示用の行を省いたもの）
visited = [start]                 # ① 行った都市を、行った順に入れるリスト
total = 0
here = start
while len(visited) < count:       # ② まだ行っていない都市がある間、くり返す
    nearest = None
    for j in range(count):
        if j in visited:          # ③ もう行った都市は、候補にしない
            continue

①② visited ── 「行った都市」を覚えておくリスト

何をしているか: visited（ビジテッド: 「訪れた」という意味）は、行った都市の番号を行った順に入れていくリストです。 はじめは出発点だけの [0] で、1つえらぶたびに append（リストの最後に足す）で1つ増えます。 len(visited)（リストの長さ = 行った都市の数）が都市の数 count と同じになったら、全部回り終えたので while のくり返しが終わります。

なぜそう書くか: 巡回セールスマン問題には「同じ都市は1回だけ」というきまりがあります。どこへ行ったかを覚えておかないと、いちばん近い2つの都市のあいだを行ったり来たりして、いつまでも終わりません。 また、このリストは最後にそのまま答え（回る順番）になります。

③ if j in visited: continue ── 行った都市は候補から外す

何をしているか: j in visited は「j がリスト visited の中にあるか」を調べる書き方で、あれば True（はい）になります。 continue（コンティニュー）は「この回の残りを飛ばして、次の j へ進む」命令です。 つまり、もう行った都市は、距離を比べる前に飛ばします。いまいる都市 here も visited に入っているので、自分自身（距離 0）をえらんでしまうこともありません。

④ if nearest is None or table[here][j] < table[here][nearest] ── いちばん近い候補をさがす

何をしているか: nearest（ニアレスト: 「いちばん近い」という意味）は、「いまのところいちばん近い候補」の番号です。 候補を1つずつ見て、table[here][j]（いまいる都市から j までの距離）が、いまの nearest までの距離より小さければ、nearest を j に書きかえます。 全部の候補を見終わったとき、nearest がいちばん近い都市になっています。 第1回・第8回の「いまのところ最短」を書きかえていく方法と同じです。

なぜ nearest is None or が要るか: さがし始めたときは、まだ候補を1つも見ていないので、nearest は None（「まだ何もない」を表す値）です。 None のまま table[here][None] と書くとエラーになるので、「nearest がまだ None なら、最初の候補をそのまま入れる」と先に書いています。 or は、左側が True なら右側を調べないので、エラーになりません。

⑤⑥ えらんだ都市へ移動し、最後に出発点へ戻る

何をしているか: えらんだ都市までの距離を total（合計）に足し、visited に足し、here（いまいる都市）を書きかえます。これで「移動した」ことになります。 while が終わったら、最後にいる都市から出発点までの距離 table[here][start] を足します。

全探索とのちがい: 全探索は「順番を1つ作る → 合計を計算する」を (n−1)! 回くり返して、いちばん短いものを残しました。 貪欲法は、順番を1つだけ、前から1か所ずつ決めていきます。いちど決めた所は、あとで「やっぱり別の順番にしよう」とやり直しません。 だから速く、そして最短とはかぎらないのです。

# 第9回 例題1（参考）: 貪欲法（どんよくほう）で、巡回セールスマン問題の「そこそこ短いルート」をすばやく作る
# 作戦は1つだけ: 「いまいる都市から、まだ行っていない都市のうち、いちばん近い都市へ進む」をくり返す。
# 最後に、第8回の全探索の答え（本当の最短）と比べる。
import math
from itertools import permutations

# 都市の名前と位置 (名前, x, y)。第8回と同じ5都市
cities = [
    ("学校", 2, 2),
    ("郵便局", 10, 3),
    ("図書館", 14, 9),
    ("カフェ", 6, 12),
    ("公園", 3, 8),
]

n = len(cities)               # 都市の数


def make_table(places):
    """第8回と同じ距離の表を作る。table[i][j] = i番から j番までの直線距離（小数第1位まで）"""
    table = []
    for i in range(len(places)):
        row = []
        for j in range(len(places)):
            dx = places[i][1] - places[j][1]
            dy = places[i][2] - places[j][2]
            row.append(round(math.sqrt(dx ** 2 + dy ** 2), 1))
        table.append(row)
    return table


def greedy(table, start):
    """貪欲法。start 番を出発し、いちばん近い都市へ進むことをくり返す。回る順番・合計距離・えらんだ記録を返す"""
    count = len(table)                # 都市の数
    visited = [start]                 # 行った都市の番号を、行った順に入れるリスト（はじめは出発点だけ）
    total = 0                         # ここまでに進んだ距離の合計
    here = start                      # いまいる都市
    steps = []                        # えらんだ記録 (いまいる都市, 候補の一覧, えらんだ都市)。表示に使う
    while len(visited) < count:       # まだ行っていない都市がある間、くり返す
        nearest = None                # 候補の中で、いまのところいちばん近い都市（まだないので None）
        candidates = []               # 候補 = まだ行っていない都市
        for j in range(count):
            if j in visited:          # もう行った都市は、候補にしない
                continue
            candidates.append(j)
            if nearest is None or table[here][j] < table[here][nearest]:
                nearest = j           # これまでの候補より近ければ、書きかえる
                                      # （同じ近さなら書きかえない。先に見つけた、番号の小さいほうのまま）
        steps.append((here, candidates, nearest))
        total = total + table[here][nearest]
        visited.append(nearest)       # えらんだ都市を「行った」に足して
        here = nearest                # そこへ移動する
    total = total + table[here][start]              # 最後に出発点へ戻る
    return visited, round(total, 1), steps


def brute_force(table):
    """全探索（第8回と同じ）。0番を出発する順番をすべて試して、いちばん短い順番と合計距離を返す"""
    best_order = None
    best_length = None
    for order in permutations(range(1, len(table))):
        total = 0
        here = 0
        for city in order:
            total = total + table[here][city]
            here = city
        total = total + table[here][0]
        if best_length is None or total < best_length:
            best_length = total
            best_order = order
    return [0] + list(best_order), round(best_length, 1)


def route_name(route):
    """回る順番を「学校 → 公園 → … → 学校」という文字列にする（最後に出発点を足す）"""
    names = []
    for city in route:
        names.append(cities[city][0])
    names.append(cities[route[0]][0])
    return " → ".join(names)

def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"


def _loop(screen, fonts, last_step, draw, hint):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = int(os.environ.get("AL2_STEP", last_step)) if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False

        h = fonts[2].render(hint, True, SUB)
        screen.blit(h, (30, screen.get_height() - 30))
        pygame.display.flip()
        if capture:

            return
        clock.tick(30)


class _MapView:
    """地点の (x, y) を、窓の中の四角 (left, top, w, h) に収まるように置きかえる。"""

    def __init__(self, places, left, top, w, h):
        xs = [p[1] for p in places]
        ys = [p[2] for p in places]
        self.x0, self.y0 = min(xs), min(ys)
        self.scale = min((w - 80) / max(max(xs) - self.x0, 1), (h - 70) / max(max(ys) - self.y0, 1))
        self.left = left + 40 + ((w - 80) - (max(xs) - self.x0) * self.scale) / 2
        self.top = top + 40 + ((h - 70) - (max(ys) - self.y0) * self.scale) / 2
        self.rect = pygame.Rect(left, top, w, h)

    def pos(self, place):
        return (int(self.left + (place[1] - self.x0) * self.scale),
                int(self.top + (place[2] - self.y0) * self.scale))

def walk_minutes(a, b):
    """場所 a から場所 b まで歩く時間（分）。第8回と同じ計算（直線距離 × WALK を、小数第1位までに丸める）"""
    dx = a[1] - b[1]
    dy = a[2] - b[2]
    return round(math.sqrt(dx ** 2 + dy ** 2) * WALK, 1)

def greedy(table, start):
    """貪欲法。start 番を出発し、いちばん近い場所へ進むことをくり返す。回る順番・合計の分・えらんだ記録を返す"""
    count = len(table)                # 場所の数
    visited = [start]                 # 行った場所の番号を、行った順に入れるリスト（はじめは出発する場所だけ）
    total = 0                         # ここまでに歩いた分の合計
    here = start                      # いまいる場所
    steps = []                        # えらんだ記録 (いまいる場所, 候補の一覧, えらんだ場所)。表示に使う
    while len(visited) < count:       # まだ行っていない場所がある間、くり返す
        nearest = None                # 候補の中で、いまのところいちばん近い場所（まだないので None）
        candidates = []               # 候補 = まだ行っていない場所
        for j in range(count):
            if j in visited:          # もう行った場所は、候補にしない
                continue
            candidates.append(j)
            if nearest is None or table[here][j] < table[here][nearest]:
                nearest = j           # これまでの候補より近ければ、書きかえる
                                      # （同じ近さなら書きかえない。先に見つけた、番号の小さいほうのまま）
        steps.append((here, candidates, nearest))
        total = total + table[here][nearest]
        visited.append(nearest)       # えらんだ場所を「行った」に足して
        here = nearest                # そこへ移動する
    total = total + table[here][start]              # 最後に、出発した場所へ戻る
    return visited, round(total, 1), steps

    result.append(names[route[0]])
    return result

def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"


def _loop(screen, fonts, last_step, draw, hint):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = int(os.environ.get("AL2_STEP", last_step)) if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False
        screen.fill(BG)
        draw(k)
        h = fonts[2].render(hint, True, SUB)
        screen.blit(h, (30, screen.get_height() - 30))
        pygame.display.flip()
        if capture:
            pygame.image.save(screen, capture)
            pygame.quit()
            return
        clock.tick(30)


class _MapView:
    """地点の (x, y) を、窓の中の四角 (left, top, w, h) に収まるように置きかえる。"""

    def __init__(self, places, left, top, w, h):
        xs = [p[1] for p in places]
        ys = [p[2] for p in places]
        self.x0, self.y0 = min(xs), min(ys)
        self.scale = min((w - 80) / max(max(xs) - self.x0, 1), (h - 70) / max(max(ys) - self.y0, 1))
        self.left = left + 40 + ((w - 80) - (max(xs) - self.x0) * self.scale) / 2
        self.top = top + 40 + ((h - 70) - (max(ys) - self.y0) * self.scale) / 2
        self.rect = pygame.Rect(left, top, w, h)

    def pos(self, place):
        return (int(self.left + (place[1] - self.x0) * self.scale),
                int(self.top + (place[2] - self.y0) * self.scale))


def _draw_panel(screen, view):

def make_table(places):
    """例題1と同じ距離の表を作る。table[i][j] = i番から j番までの直線距離（小数第1位まで）"""
    table = []
    for i in range(len(places)):
        row = []
        for j in range(len(places)):
            dx = places[i][1] - places[j][1]
            dy = places[i][2] - places[j][2]
            row.append(round(math.sqrt(dx ** 2 + dy ** 2), 1))
        table.append(row)
    return table


def greedy(table, start):
    """貪欲法（例題1と同じ。表示用の記録 steps だけ省いた）。回る順番と合計距離を返す"""
    count = len(table)
    visited = [start]                 # 行った都市の番号を、行った順に入れるリスト
    total = 0
    here = start                      # いまいる都市
    while len(visited) < count:       # まだ行っていない都市がある間、くり返す
        nearest = None
        for j in range(count):
            if j in visited:          # もう行った都市は、候補にしない
                continue
            if nearest is None or table[here][j] < table[here][nearest]:
                nearest = j           # これまでの候補より近ければ、書きかえる
                                      # （同じ近さなら書きかえない。先に見つけた、番号の小さいほうのまま）
        total = total + table[here][nearest]
        visited.append(nearest)
        here = nearest
    total = total + table[here][start]              # 最後に出発点へ戻る
    return visited, round(total, 1)


def brute_force(table):
    """全探索（第8回と同じ）。いちばん短い順番・合計距離・試した順番の数を返す"""
    best_order = None
    best_length = None
    tried = 0
    for order in permutations(range(1, len(table))):
        total = 0
        here = 0
        for city in order:
            total = total + table[here][city]
            here = city
        total = total + table[here][0]
        tried = tried + 1
        if best_length is None or total < best_length:
            best_length = total
            best_order = order
    return [0] + list(best_order), round(best_length, 1), tried


def route_name(route):
    """回る順番を「学校 → 公園 → … → 学校」という文字列にする（最後に出発点を足す）"""
    names = []
    for city in route:
        names.append(cities[city][0])
    names.append(cities[route[0]][0])
    return " → ".join(names)

def _font(size, bold=False):
    for path in FONT_FILES:

            return pygame.font.Font(path, size)
    return pygame.font.SysFont(FONT_NAMES, size, bold=bold)


def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"


def _loop(screen, fonts, last_step, draw, hint):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = int(os.environ.get("AL2_STEP", last_step)) if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False
        screen.fill(BG)
        draw(k)
        h = fonts[2].render(hint, True, SUB)
        screen.blit(h, (30, screen.get_height() - 30))
        pygame.display.flip()
        if capture:
            pygame.image.save(screen, capture)
            pygame.quit()
            return
        clock.tick(30)


class _MapView:
    """地点の (x, y) を、窓の中の四角 (left, top, w, h) に収まるように置きかえる。"""

    def __init__(self, places, left, top, w, h):
        xs = [p[1] for p in places]
        ys = [p[2] for p in places]
        self.x0, self.y0 = min(xs), min(ys)
        self.scale = min((w - 80) / max(max(xs) - self.x0, 1), (h - 70) / max(max(ys) - self.y0, 1))
        self.left = left + 40 + ((w - 80) - (max(xs) - self.x0) * self.scale) / 2
        self.top = top + 40 + ((h - 70) - (max(ys) - self.y0) * self.scale) / 2
        self.rect = pygame.Rect(left, top, w, h)

    def pos(self, place):
        return (int(self.left + (place[1] - self.x0) * self.scale),
                int(self.top + (place[2] - self.y0) * self.scale))


def _draw_panel(screen, view):
    """地図の背景（角の丸い四角）を描く。"""
    pygame.draw.rect(screen, PANEL, view.rect, border_radius=10)


def _draw_route(screen, view, places, route, legs, color, width):
    """route の順に、最初の legs 本ぶんの線を引く（最後の1本は、出発点へ戻る線）。"""

    for k in range(min(legs, len(loop) - 1)):
        pygame.draw.line(screen, color, view.pos(places[loop[k]]), view.pos(places[loop[k + 1]]), width)


def _draw_places(screen, fonts, view, places, marks, start):
    """地点の丸・番号・名前を描く。出発点（start）は橙。marks = {番号: 丸の中に書く文字}"""
    _, mid, small = fonts
    for i, place in enumerate(places):
        x, y = view.pos(place)
        pygame.draw.circle(screen, (26, 26, 26), (x, y), 15)
        pygame.draw.circle(screen, AMBER if i == start else GREEN, (x, y), 15, 3)
        t = mid.render((marks or {}).get(i, str(i)), True, TEXT)
        screen.blit(t, (x - t.get_width() // 2, y - t.get_height() // 2 + 2))
        name = small.render(_fit(small, place[0], 190), True, SUB)
        ny = y - 36 if y - 36 > view.rect.top + 4 else y + 18
        nx = min(max(x - name.get_width() // 2, view.rect.left + 4), view.rect.right - name.get_width() - 4)
        back = pygame.Rect(nx - 3, ny, name.get_width() + 6, name.get_height())
        pygame.draw.rect(screen, PANEL, back, border_radius=4)
        screen.blit(name, (nx, ny))


def _order_marks(route):
    """回る順番を、丸の中に書く文字にする（出発点は S、あとは 1, 2, …）。"""
    marks = {route[0]: "S"}
    for k in range(1, len(route)):
        marks[route[k]] = str(k)
    return marks

def make_table(places):
    """歩く時間の表を作る（第8回・演習1と同じ計算）。table[i][j] = i番から j番まで歩く分"""
    table = []
    for i in range(len(places)):
        row = []
        for j in range(len(places)):
            dx = places[i][1] - places[j][1]
            dy = places[i][2] - places[j][2]
            row.append(round(math.sqrt(dx ** 2 + dy ** 2) * WALK, 1))
        table.append(row)
    return table


def greedy(table, start):
    """貪欲法（演習1と同じ。表示用の記録 steps だけ省いた）。回る順番と合計の分を返す"""
    count = len(table)
    visited = [start]                 # 行った場所の番号を、行った順に入れるリスト
    total = 0
    here = start                      # いまいる場所
    while len(visited) < count:       # まだ行っていない場所がある間、くり返す
        nearest = None
        for j in range(count):
            if j in visited:          # もう行った場所は、候補にしない
                continue
            if nearest is None or table[here][j] < table[here][nearest]:
                nearest = j           # これまでの候補より近ければ、書きかえる
                                      # （同じ近さなら書きかえない。先に見つけた、番号の小さいほうのまま）
        total = total + table[here][nearest]
        visited.append(nearest)
        here = nearest
    total = total + table[here][start]              # 最後に、出発した場所へ戻る
    return visited, round(total, 1)


def brute_force(table):
    """全探索（第8回と同じ）。いちばん早い順番・合計の分・試した順番の数を返す"""
    best_order = None
    best_total = None
    tried = 0
    for order in permutations(range(1, len(table))):
        total = 0
        here = 0
        for place in order:
            total = total + table[here][place]
            here = place
        total = total + table[here][0]
        tried = tried + 1
        if best_total is None or total < best_total:
            best_total = total
            best_order = order
    return [0] + list(best_order), round(best_total, 1), tried


def route_names(route):
    """回る順番（番号）を、名前の並びにする（最後に、出発した場所を足す）"""
    result = []
    for place in route:
        result.append(spots[place][0])
    result.append(spots[route[0]][0])
    return result

def how_long(sec):
    """秒を、読みやすい単位（秒・分・時間・日・年）の文字にする。とても大きいときは「10の何乗 年」と書く"""
    years = sec / (365 * 24 * 3600)
    if years >= 1000000:
        return f"約10の{len(str(int(years))) - 1}乗 年"      # けたの数から「10の何乗」かを出す
    for size, unit in [(365 * 24 * 3600, "年"), (24 * 3600, "日"), (3600, "時間"), (60, "分")]:
        if sec >= size:
            return f"約{sec / size:,.1f}{unit}"
    if sec < 0.01:
        return "0.01秒より短い"
    return f"約{sec:.2f}秒"

def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"


def _loop(screen, fonts, last_step, draw, hint):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = int(os.environ.get("AL2_STEP", last_step)) if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False
        screen.fill(BG)
        draw(k)
        h = fonts[2].render(hint, True, SUB)
        screen.blit(h, (30, screen.get_height() - 30))
        pygame.display.flip()
        if capture:
            pygame.image.save(screen, capture)
            pygame.quit()
            return
        clock.tick(30)


class _MapView:
    """地点の (x, y) を、窓の中の四角 (left, top, w, h) に収まるように置きかえる。"""

    def __init__(self, places, left, top, w, h):
        xs = [p[1] for p in places]
        ys = [p[2] for p in places]
        self.x0, self.y0 = min(xs), min(ys)
        self.scale = min((w - 80) / max(max(xs) - self.x0, 1), (h - 70) / max(max(ys) - self.y0, 1))
        self.left = left + 40 + ((w - 80) - (max(xs) - self.x0) * self.scale) / 2
        self.top = top + 40 + ((h - 70) - (max(ys) - self.y0) * self.scale) / 2
        self.rect = pygame.Rect(left, top, w, h)

    def pos(self, place):
        return (int(self.left + (place[1] - self.x0) * self.scale),
                int(self.top + (place[2] - self.y0) * self.scale))


def _draw_panel(screen, view):
