動的計画法（bitDP）

第8回の全探索は必ず最適解を出しますが、12都市で終わらなくなりました。 第9回の貪欲法は一瞬で終わりますが、最適解とはかぎりませんでした。 第10回で学ぶ動的計画法は、 必ず最適解を出しながら、全探索よりずっと速い方法です。

同じ計算を何度もしていることに気づいたら、答えをメモしておいて使い回す。 たとえば「12×15」を1日に何度も計算するなら、最初の1回で180とメモしておけば、 2回目以降は計算し直す必要がありません。 動的計画法は、この「一度計算した答えをメモして使い回す」という考え方です。

全探索のむだ

全探索は「0 → 1 → 2 → 3 → …」と「0 → 2 → 1 → 3 → …」を、まったく別のものとして最後まで調べます。 しかし2つの道は、4つ目の都市に着いた時点で状況がまったく同じです。 どちらも「0・1・2・3 を回り終えて、いま 3 にいる」という状態だからです。

残っている都市も同じ、いる場所も同じなので、ここから先の最短の進み方も同じになります。 違うのは「ここまでにかかった距離」だけです。 だとすれば、短いほうの距離だけを覚えておけば十分で、長いほうの道はもう調べる必要がありません。

覚えておくべき2つのこと

覚えること意味
回った都市の集合どの都市をすでに回ったか（順番は関係ない）
いまいる都市最後に到着した都市

2つが同じなら、そこまでのいちばん短い距離だけを覚えておけば十分です。 「どんな順番で来たか」は、この先の判断にまったく影響しません。

集合をビットで表す

「回った都市の集合」を、Pythonのリストや集合ではなく1つの整数で表します。 都市が5個なら5けたの2進数を使い、i番の都市を回っていれば i けた目を 1 にします。

書き方意味
1 << ii番の都市だけを表す数（1を左へ i けたずらす）
visited | (1 << i)集合に i番の都市を足す
visited & (1 << i)集合に i番の都市が入っているか調べる（0以外なら入っている）

整数1つで集合を表せるので、best[visited][here] のように リストの番号としてそのまま使えます。速く、書き方も短くなります。 ビットを使った動的計画法なので、bitDP（ビットディーピー）と呼ばれます。

例題 1

ビットで集合を表す練習

bitDP を書く前に、ビットで集合を表す練習をします。 <<、|、& の3つの記号だけ覚えれば足ります。

Python ── AL2-10-ex1-ref.py
city_names = ["学校", "郵便局", "図書館", "カフェ", "公園"]
n = len(city_names)

def pad(text, width):
    """全角文字を2文字ぶんとして数え、右側に空白を足して表示の幅をそろえる"""
    length = 0
    for ch in text:
        if ord(ch) > 0x2000:
            length = length + 2
        else:
            length = length + 1
    return text + " " * (width - length)

def show(bits):
    """bits を2進数と、回った都市の名前で表示する"""
    binary = format(bits, "05b")
    visited = []
    for i in range(n):
        if bits & (1 << i):
            visited.append(city_names[i])
    if len(visited) == 0:
        names = "（まだどこにも行っていない）"
    else:
        names = "、".join(visited)
    print(f"  {bits:>2} = 2進数 {binary}  →  {names}")

print("2進数1つで「回った都市の集合」を表す")
print("-" * 52)
show(0)
show(1)
show(3)
show(5)
show(31)
print("-" * 52)
print()

print("1つの都市を表す数（1 << i は「1を左へ i けたずらす」という意味）")
print("-" * 52)
for i in range(n):
    print("  " + pad(city_names[i], 8) + f"→ 1 << {i} = {1 << i:>2} = 2進数 {format(1 << i, '05b')}")
print("-" * 52)
print()

print("集合に都市を1つ足す（| は「または」。けたごとに 1 があれば 1 にする）")
print("-" * 52)
bits = 0
for i in range(n):
    before = bits

print("-" * 52)
print()

print("集合に都市が入っているか調べる（& は「かつ」。両方 1 のけただけ 1 にする）")

例題 2

bitDP で巡回セールスマン問題を解く

bitDP で巡回セールスマン問題を解きます。 best[visited][here] という表を作り、 「visited の都市を回り終えて、いま here にいる」ときの最小距離を記録していきます。

例題2（参考）── 完成したコード。コメントなしで全体の流れをつかむ。保存するなら AL2-10-ex2-ref.py の名前で

Python ── AL2-10-ex2-ref.py
import math
from itertools import permutations

cities = [
    ("学校", 2, 2),
    ("郵便局", 10, 3),
    ("図書館", 14, 9),
    ("カフェ", 6, 12),
    ("公園", 3, 8),
]

n = len(cities)
INF = float("inf")

distance = []
for i in range(n):
    row = []
    for j in range(n):
        d = math.sqrt((cities[i][1] - cities[j][1]) ** 2 + (cities[i][2] - cities[j][2]) ** 2)
        row.append(d)
    distance.append(row)

full = (1 << n) - 1

best = []
for visited in range(1 << n):
    best.append([INF] * n)

best[1 << 0][0] = 0.0

for visited in range(1 << n):
    for here in range(n):
        if best[visited][here] == INF:
            continue
        for next_city in range(n):
            if visited & (1 << next_city):
                continue
            new_visited = visited | (1 << next_city)
            new_length = best[visited][here] + distance[here][next_city]
            if new_length < best[new_visited][next_city]:
                best[new_visited][next_city] = new_length

answer = INF
last_city = None
for here in range(n):
    if best[full][here] == INF:
        continue
    total = best[full][here] + distance[here][0]
    if total < answer:
        answer = total
        last_city = here

print("動的計画法（bitDP）の表の一部")
print("（visited = 回った都市の集合を2進数で表したもの、here = いまいる都市）")
print("-" * 62)
print("visited           here=0 here=1   here=2   here=3   here=4")
for visited in [1, 3, 7, 15, 31]:
    line = f"   {format(visited, '05b')}        "
    for here in range(n):
        value = best[visited][here]
        if value == INF:
            line = line + "     -   "
        else:
            line = line + f"{round(value, 1):>8} "
    print(line)
print("-" * 62)
print("「-」は「その状態にはたどり着けない」ことを表す")
print()

print("bitDP の答え:", round(answer, 1))
print("最後に立ち寄った都市:", cities[last_city][0])
print()

brute_best = None
for order in permutations(range(1, n)):
    total = 0.0
    here = 0
    for city in order:
        total = total + distance[here][city]
        here = city
    total = total + distance[here][0]
    if brute_best is None or total < brute_best:
        brute_best = total

print("全探索の答え:", round(brute_best, 1))
if abs(answer - brute_best) < 0.0001:
    print("2つの答えは一致した。bitDP は必ず最適解を出す。")

print()
print("表のマスの数:", (1 << n) * n, "個（2の5乗 × 5）")
print("全探索が試した順番の数: 24 通り")

標準課題: アルゴリズムの仕組みを図で説明する

第10回のGoogleスライドを新しく作り、見出しを「第10回: bitDP の状態と表」にしてください。 その回のアルゴリズムの仕組みを、コード上の変数や自分で決めた数値を用いて図で説明します。 枚数は自由です（1枚に収まらなければ分けてかまいません）。

毎回同じ4つの約束
  1. 例題を自分で決めた数値で動かし、アルゴリズムの仕組みをコード上の変数や数値を用いて図形で説明する
  2. 画像の貼り付けは不可（図形・矢印・テキストボックスで描く。クリックすると1つずつ選べる状態）
  3. 図の中に自分の数値を入れる
  4. 文章は1枚につき1〜2行まで
標準課題

bitDP の状態と表を図形で描く

1. 自分の数値を決めて、例題を動かす

AL2-10-ex2.py を開き、cities の座標を4か所以上書き換える。 保存して実行し、実行結果をそのまま残しておく（あとで図と見比べる）。

2. 実行結果を見ながら、図形で描く

実行結果の表の5行（00001 → 00011 → 00111 → 01111 → 11111）を、上から下へ5つの「状態の箱」として描く。各箱に「回った都市の集合（2進数と都市名）」と「いまいる都市ごとの最短距離」を書き、箱の間を「都市を1つ足す」矢印でつなぐ。最後の箱から「学校へ戻る距離」を足して答えを出す計算を書く。

図に必ず入れる3つ

  1. 5つの状態の箱（2進数と、それが表す回った都市）
  2. 各状態の「いまいる都市ごとの最短距離」（実行結果の表の値）
  3. 最後の行の値に「学校へ戻る距離」を足して、いちばん短いものを選ぶ計算（= bitDP の答え）

3. 文章を1〜2行だけ書く

図から分かることを、自分の数値を使って1〜2行で書く。 「自分の数値では○○が△△になった」の形。

課題要件（満点の条件）

5行の値が実行結果の表と一致し、計算した答えが実行結果の「bitDP の答え」と一致する

Googleスライドでの図の描き方

描きたいものやり方
マス目・箱・丸挿入 → 図形 → 図形 から四角や丸を置く。Ctrl+D（Mac は Command+D）で複製すると速い
矢印・線挿入 → 線 → 矢印。図形の端にくっつけると、動かしてもついてくる
数値・文字挿入 → テキストボックス。図形をダブルクリックして中に直接書いてもよい
色分け図形を選んで、ツールバーの塗りつぶしの色・枠線の色
木（枝分かれ）上に1つ箱を置き、下の段に箱を並べて矢印でつなぐ。段ごとに横にそろえる

授業ページの図のスクリーンショット、AIが作った画像、手描きの写真はすべて不可です。 図形で描いたものだけを受けつけます。

解答例

標準課題のスライドの例（あくまで例）

自分の数値に書き換える前の、例題の数値で描いた例です。 図形（四角・丸・矢印・テキストボックス）だけで描いてあり、図の中に数値が入っています。 文章は下の1〜2行だけです。自分の数値で同じように描けば、課題要件を満たします。

穴埋めの答え

ファイル穴答え

AL2-10-ex2.py穴1visited & (1 << next_city)

AL2-10-ex2.py穴3new_length < best[new_visited][next_city]

確かめ用の数値

問い1の根拠になる数値

都市の数全探索bitDP
12都市約8秒0.01秒ほど
14都市終わらない0.04秒ほど
16都市終わらない0.2秒ほど
20都市約12京通り（約800年）6秒ほど

問い2: 9（2進数で 01001）。 学校は0番なので 1 << 0 = 1、カフェは3番なので 1 << 3 = 8。足して9です。

ほかの確認用: 22 = 10110（郵便局・図書館・公園）、 26 = 11010（郵便局・カフェ・公園）、都市が10個なら集合は1,024通り。
