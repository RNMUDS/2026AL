重み付きグラフとは

第3回では、路線図を「どの駅とどの駅がつながっているか」だけのグラフに書き写しました。 しかし、乗換案内で知りたいのは「つながっているか」だけではありません。 同じ1駅ぶんでも、急行で3分の区間もあれば、30分かかる区間もあります。 第4回では、辺ごとにかかる時間を書き込んだグラフを作り、 これまでの幅優先探索では「いちばん早く着く道」が求められない場面を確かめます。

乗換案内アプリで経路を調べると、「乗りかえ0回・所要45分」と「乗りかえ2回・所要28分」のように、 性質の違う候補が並びます。乗りかえの回数がいちばん少ない行き方と、所要時間がいちばん短い行き方は、別のものです。 第1回から第3回までの幅優先探索が求めていたのは、前者の「乗りかえの回数がいちばん少ない行き方」でした。

用語

用語意味路線図でいうと
重み辺ごとに書き込む数値。その辺を通るのにかかるもの区間の乗車時間（分）
重み付きグラフすべての辺に重みが付いているグラフ区間ごとに時間を書いた路線図
コスト重みの言いかえ。「その道を通るために支払うもの」という意味で使う時間・運賃
経路出発点から目的地までの、頂点の並び（道）新宿 → 渋谷 → 品川
経路の長さ（合計コスト）経路が通る辺の重みを全部足したもの7分 ＋ 9分 ＝ 16分

重みになるもの

あつかうもの重みになるもの小さいほど良いか
路線図乗車時間（分）小さいほど良い
道路地図距離（km）、通行料金（円）小さいほど良い
床コスト付き迷路そのマスを通り抜ける時間（秒）小さいほど良い
通信ネットワーク通信の遅れ（ミリ秒）小さいほど良い

後期の授業であつかう重みは、すべて0以上の数値です。 マイナスの重みが混ざると、第5回から学ぶダイクストラ法は正しく動きません。理由は第5回で確かめます。 第2回の迷路も、下の図のようにマスごとに「通り抜ける時間」を書けば重み付きグラフになります（第7回であつかう）。

重み付きグラフをPythonに書き写す

第3回の隣接リストに、時間を書き足すだけです。 となりの駅の名前だけを並べていたところを、("駅の名前", 時間) の2つ組（タプル: 丸かっこで値をまとめたもの）にします。 路線は行きも帰りも同じ時間なので、第3回と同じく、1本の路線を両方の駅の行に書きます。

経路の合計時間を求める

「新宿 → 渋谷 → 品川」の合計時間は、隣り合う2駅の組（新宿—渋谷、渋谷—品川）ごとに時間を調べて足せば求まります。 例題1の route_minutes 関数は、これを前から1組ずつくり返します。

幅優先探索は時間を見ていない

では、第1〜3回の幅優先探索で 新宿 → 品川 をさがすとどうなるでしょうか。 幅優先探索は、キューの左から駅を取り出し、まだ見つけていないとなりの駅をキューの右に入れる、をくり返すのでした。 下の図で、1手順ずつ追ってみます。

幅優先探索は、出発点から「路線1本で行ける駅」「2本で行ける駅」「3本で行ける駅」…の順に、同心円のように広げていきます。 品川は新宿から路線1本で行けるので、手順1で見つかり、「来た駅 = 新宿」がその場で決まります。 あとから渋谷経由の 16分 の道が出てきても、品川はもう見つけた駅なので、書き直しません。 幅優先探索がいちばん少なくするのは路線の本数で、時間の合計ではありません。

「最短」には2つの意味がある

言い方意味求める方法
辺の数が最も少ない経路乗りかえや歩数がいちばん少ない行き方幅優先探索（第1〜3回）
重みの合計が最も小さい経路かかる時間や料金がいちばん小さい行き方全探索（今回の例題2）、ダイクストラ法（第5回から）

重みがすべて同じ値なら、2つの答えは一致します。 重みがばらばらのときは、例題2で確かめるように答えがずれることがあります。

def route_minutes(route):
    """route（駅を通る順に並べたリスト）の合計時間を求める。"""
    total = 0                               # 合計は 0 から始める
    for i in range(len(route) - 1):         # 隣り合う2駅の組を、前から順に1組ずつ見る
        here = route[i]                     # いまいる駅
        next_station = route[i + 1]         # 次に行く駅

                total = total + minutes         # ★ その路線の時間を、いままでの合計に足して書き戻す
    return total

def _graph_parts(railway):
    """隣接リストから、丸にする駅の名前と、線（駅, 駅, 時間）の一覧を作る。
    となりの一覧には書いたのに、鍵（左側）に書き忘れた駅も丸として描けるように足しておく。"""
    names = list(railway)
    for a in railway:
        for b, _ in railway[a]:
            if b not in names:
                names.append(b)
    edges = []
    for a in railway:
        for b, w in railway[a]:
            if not any({a, b} == {x, y} for x, y, _ in edges):
                edges.append((a, b, w))
    return names, edges

def _weight(railway, a, b):
    """a から b への時間。直接つながっていなければ None。"""
    for name, w in railway.get(a, []):
        if name == b:
            return w
    return None

def _pairs(route):
    """道（駅の並び）を、隣り合う2駅の組の一覧にする。"""
    return [(route[i], route[i + 1]) for i in range(len(route) - 1)]

def _crossings(order, edges):
    """円の上に order の順で頂点を並べたとき、線どうしが何回交わるかを数える。"""
    at = {name: i for i, name in enumerate(order)}
    count = 0
    for i, (a, b, _) in enumerate(edges):
        lo, hi = sorted((at[a], at[b]))
        for c, d, _ in edges[i + 1:]:
            if len({a, b, c, d}) < 4:
                continue
            inside = (lo < at[c] < hi) + (lo < at[d] < hi)
            count += inside == 1
    return count

def _layout(names, edges, cx=255, cy=320, radius=200):
    """頂点を円の上に等間隔で並べる（いちばん上から時計回り）。
    頂点が8個以下なら、線の交わりがいちばん少なくなる並べ方を全部試して選ぶ。"""
    order = list(names)
    if 3 < len(order) <= 8:
        from itertools import permutations
        best = None
        for rest in permutations(order[1:]):
            cand = [order[0], *rest]
            k = _crossings(cand, edges)
            if best is None or k < best[0]:
                best = (k, cand)
        order = best[1]
    n = len(order)
    return {name: (cx + radius * math.sin(2 * math.pi * i / n), cy - radius * math.cos(2 * math.pi * i / n))
            for i, name in enumerate(order)}

def _graph_parts(railway):

def _crossings(order, edges):
    """円の上に order の順で頂点を並べたとき、線どうしが何回交わるかを数える。"""
    at = {name: i for i, name in enumerate(order)}
    count = 0
    for i, (a, b, _) in enumerate(edges):
        lo, hi = sorted((at[a], at[b]))
        for c, d, _ in edges[i + 1:]:
            if len({a, b, c, d}) < 4:
                continue
            inside = (lo < at[c] < hi) + (lo < at[d] < hi)
            count += inside == 1
    return count


def _layout(names, edges, cx=255, cy=320, radius=200):
    """頂点を円の上に等間隔で並べる（いちばん上から時計回り）。
    頂点が8個以下なら、線の交わりがいちばん少なくなる並べ方を全部試して選ぶ。"""
    order = list(names)
    if 3 < len(order) <= 8:
        from itertools import permutations
        best = None
        for rest in permutations(order[1:]):
            cand = [order[0], *rest]
            k = _crossings(cand, edges)
            if best is None or k < best[0]:
                best = (k, cand)
        order = best[1]
    n = len(order)
    return {name: (cx + radius * math.sin(2 * math.pi * i / n), cy - radius * math.cos(2 * math.pi * i / n))
            for i, name in enumerate(order)}

def route_minutes(route):

def _graph_parts(railway):
    """隣接リストから、丸にする駅の名前と、線（駅, 駅, 時間）の一覧を作る。
    となりの一覧には書いたのに、鍵（左側）に書き忘れた駅も丸として描けるように足しておく。"""
    names = list(railway)
    for a in railway:
        for b, _ in railway[a]:
            if b not in names:
                names.append(b)
    edges = []
    for a in railway:
        for b, w in railway[a]:
            if not any({a, b} == {x, y} for x, y, _ in edges):
                edges.append((a, b, w))
    return names, edges

def _weight(railway, a, b):
    """a から b への時間。直接つながっていなければ None。"""
    for name, w in railway.get(a, []):
        if name == b:
            return w
    return None

def _pairs(route):
    """道（駅の並び）を、隣り合う2駅の組の一覧にする。"""
    return [(route[i], route[i + 1]) for i in range(len(route) - 1)]

def _crossings(order, edges):
    """円の上に order の順で頂点を並べたとき、線どうしが何回交わるかを数える。"""
    at = {name: i for i, name in enumerate(order)}
    count = 0
    for i, (a, b, _) in enumerate(edges):
        lo, hi = sorted((at[a], at[b]))
        for c, d, _ in edges[i + 1:]:
            if len({a, b, c, d}) < 4:
                continue
            inside = (lo < at[c] < hi) + (lo < at[d] < hi)
            count += inside == 1
    return count

def _layout(names, edges, cx=255, cy=320, radius=200):
    """頂点を円の上に等間隔で並べる（いちばん上から時計回り）。
    頂点が8個以下なら、線の交わりがいちばん少なくなる並べ方を全部試して選ぶ。"""
    order = list(names)
    if 3 < len(order) <= 8:
        from itertools import permutations
        best = None
        for rest in permutations(order[1:]):
            cand = [order[0], *rest]
            k = _crossings(cand, edges)
            if best is None or k < best[0]:
                best = (k, cand)
        order = best[1]
    n = len(order)
    return {name: (cx + radius * math.sin(2 * math.pi * i / n), cy - radius * math.cos(2 * math.pi * i / n))
            for i, name in enumerate(order)}

def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:
        text = text[:-1]
    return text + "…"

def _loop(screen, fonts, last_step, draw):

    while True:

            if event.type == pygame.KEYDOWN:

                    return
                if event.key == pygame.K_SPACE:

def _graph_parts(railway):
    """隣接リストから、丸にする駅の名前と、線（駅, 駅, 時間）の一覧を作る。

def _pairs(route):

def _crossings(order, edges):
    """円の上に order の順で頂点を並べたとき、線どうしが何回交わるかを数える。"""
    at = {name: i for i, name in enumerate(order)}
    count = 0
    for i, (a, b, _) in enumerate(edges):
        lo, hi = sorted((at[a], at[b]))
        for c, d, _ in edges[i + 1:]:
            if len({a, b, c, d}) < 4:
                continue
            inside = (lo < at[c] < hi) + (lo < at[d] < hi)
            count += inside == 1
    return count


def _layout(names, edges, cx=255, cy=320, radius=200):
    """頂点を円の上に等間隔で並べる（いちばん上から時計回り）。
    頂点が8個以下なら、線の交わりがいちばん少なくなる並べ方を全部試して選ぶ。"""
    order = list(names)
    if 3 < len(order) <= 8:
        from itertools import permutations
        best = None
        for rest in permutations(order[1:]):
            cand = [order[0], *rest]
            k = _crossings(cand, edges)
            if best is None or k < best[0]:
                best = (k, cand)
        order = best[1]
    n = len(order)
    return {name: (cx + radius * math.sin(2 * math.pi * i / n), cy - radius * math.cos(2 * math.pi * i / n))
            for i, name in enumerate(order)}

def _fit(font, text, width):
    """text が width ピクセルに収まらなければ、後ろを「…」にして縮める。"""
    if font.size(text)[0] <= width:
        return text
    while text and font.size(text + "…")[0] > width:

    return text + "…"


def _loop(screen, fonts, last_step, draw):
    """窓のくり返し処理。draw(k) が k 手順目の画面を描く。"""
    capture = os.environ.get("AL2_CAPTURE")      # 授業ページの画像を作るときだけ使う
    k = last_step if capture else 0
    playing = False
    clock = pygame.time.Clock()
    last = pygame.time.get_ticks()
    while True:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                pygame.quit()
                return
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE:
                    pygame.quit()
                    return
                if event.key == pygame.K_SPACE:
                    playing = not playing
                if event.key == pygame.K_RIGHT and k < last_step:
                    k += 1
                    playing = False
                if event.key == pygame.K_r:
                    k, playing = 0, False
        if playing and pygame.time.get_ticks() - last >= STEP_MS:
            last = pygame.time.get_ticks()
            if k < last_step:
                k += 1
            else:
                playing = False
        screen.fill(BG)
        draw(k)
        hint = fonts[2].render("スペース: 再生／一時停止   →: 1手順すすめる   R: 最初から   Esc: 終わる", True, SUB)

        pygame.display.flip()
        if capture:

            return
        clock.tick(30)
