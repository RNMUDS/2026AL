説明

1.1 CSVファイルとは

CSV（Comma-Separated Values）は、データをカンマで区切ったテキストファイルです。Excel やデータベースのデータをやり取りするのによく使われます。

CSV
名前,数学,英語,国語
田中太郎,85,72,90
佐藤花子,92,88,76
鈴木一郎,78,95,83

1.2 Python での CSV 読み書き

Python には csv モジュールが標準で用意されています。

Python
import csv

# --- 書き込み ---
with open("data.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["名前", "点数"])    # ヘッダー行
    writer.writerow(["田中", 85])        # データ行
    writer.writerow(["佐藤", 92])

# --- 読み込み ---
with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)       # 1行目（ヘッダー）を読み飛ばす
    for row in reader:
        name = row[0]           # 文字列
        score = int(row[1])     # 数値に変換
        print(f"{name}: {score}点")
CSVはExcelの表を「テキストファイル」にしたもの。メモ帳でも開けるシンプルなデータ形式です。プログラム間でデータをやり取りするとき、一番よく使われる形式の1つです。

1.3 安定ソート（Stable Sort）とは

読み方: stable sort = ステーブル・ソート（日本語では「安定ソート」）。 対義語の unstable sort＝アンステーブル・ソート（不安定ソート）。stable は「安定した／ぐらつかない」という意味で、同じキーの要素の相対順序が動かないことを表します。

安定ソートとは、同じ値の要素が元の配列での順序を保つソートのことです。

トランプを「数字」で並び替えるとき、同じ数字（例: ハート7とスペード7）が来た場合、並べる前の順番のままに残るのが安定ソート。シャッフルされてしまうのが不安定ソート。複数の条件で並べ替えたいときに、この「順序保持」がとても大切になります。

1.4 安定ソートが重要な場面

複数のキーでソートしたい場合に安定ソートが必要です。

例: 成績データを「数学の点数 → 名前の五十音順」で並べたい場合

  1. まず名前の五十音順でソート
  2. 次に数学の点数で安定ソート

→ 同じ点数の人は五十音順が保たれる！

❓ なぜ「末尾から配置」すると安定ソートになるの？

分布数えソートで、累積度数を使って要素を出力配列に置くとき、入力を末尾から走査する理由はここにあります。

走査の向き同じキーを持つ要素の順序安定性
末尾から（range(n-1, -1, -1)） 後ろの要素ほど右の空き位置に置かれる → 元の並びが保たれる 安定 ✓
先頭から（range(n)） 先に出た要素が右の空き位置に置かれる → 並びが反転 不安定 ✗

💡 まとめ: 累積度数 count[key] は「そのキーの最後に入る位置 + 1」を表すため、末尾から見ていけば「最後 → 後ろから2番目 → …」と右から左へ詰めていくことになり、元の順序が保たれます。例題2で実際に体験できます。

1.5 各ソートアルゴリズムの安定性

アルゴリズム安定？理由
挿入ソート安定「より大きい」場合のみ交換
バブルソート安定「より大きい」場合のみ交換
分布数えソート安定末尾から配置すれば安定
選択ソート不安定離れた要素を交換する

1.6 基数ソート（Radix Sort）入門

読み方: radix sort = ラディックス・ソート（日本語では「基数ソート」）。 radix は「基数（=数を表すときの底、10進数なら10）」を意味するラテン語由来の単語で、桁ごとに処理することが名前の由来です。 派生語の counting sort＝カウンティング・ソート（分布数えソート／計数ソート）も同じ系統のアルゴリズム。

基数ソートは、数値を桁ごとに分布数えソートするアルゴリズムです。

トランプの数字を並べるときに、まず「1の位」だけ見て山を作り、次に「10の位」だけ見て山を作り直す…という作業を桁の数だけ繰り返すイメージ。郵便番号でハガキを仕分けるときも、上から1桁ずつ仕分け箱に入れていけば自動的に番号順になります。基数ソートはこの「桁ごとの仕分け」を機械的に行うアルゴリズムです。
  • 各桁のソートには安定ソートを使う必要がある（だから分布数えソートを使う）
  • 計算量: O(d * (n + k))（d: 最大桁数、n: 要素数、k: 基数（通常10））

例題 1

CSVファイルにデータを書き込んで読み込む

Python
import csv  # CSVモジュールを読み込む

def write_scores_csv(filename, data):
    """成績データをCSVファイルに書き出す"""
    with open(filename, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow(["name", "math", "english"])  # ヘッダー
        for row in data:
            writer.writerow(row)
    print(f"CSVファイルを保存しました: {filename}")

def read_scores_csv(filename):
    """CSVファイルから成績データを読み込む"""
    records = []
    with open(filename, "r", encoding="utf-8") as f:
        reader = csv.reader(f)
        header = next(reader)  # ヘッダーを読み飛ばす
        for row in reader:
            name = row[0]
            math_score = int(row[1])
            english_score = int(row[2])
            records.append([name, math_score, english_score])
    print(f"読み込み完了: {len(records)} 件")
    return records

# --- 実行 ---
sample_data = [
    ["Tanaka", 85, 72],
    ["Sato", 92, 88],
    ["Suzuki", 78, 95],
    ["Yamada", 65, 80],
]

write_scores_csv("scores.csv", sample_data)
loaded = read_scores_csv("scores.csv")
for record in loaded:
    print(f"  {record[0]}: 数学={record[1]}, 英語={record[2]}")

例題 2

安定ソートの動作を確認する

Python
def counting_sort_stable(data, key_func, max_val):
    """安定な分布数えソート（キー関数版）"""
    count = [0] * (max_val + 1)
    for item in data:
        count[key_func(item)] += 1

    for i in range(1, len(count)):
        count[i] += count[i - 1]

    output = [None] * len(data)
    for i in range(len(data) - 1, -1, -1):  # 末尾から配置（安定のポイント）
        key = key_func(data[i])
        position = count[key] - 1
        output[position] = data[i]
        count[key] -= 1

    return output

# --- テストデータ ---
students = [
    ("Sato", 80), ("Tanaka", 90),
    ("Suzuki", 80), ("Yamada", 90),
    ("Ito", 80), ("Watanabe", 90),
]

result = counting_sort_stable(students, key_func=lambda s: s[1], max_val=100)

score_80 = [name for name, score in result if score == 80]
print(f"80点の順序: {score_80}")
print(f"元の順序保持: {score_80 == ['Sato', 'Suzuki', 'Ito']}")

例題 3

基数ソートの基本実装

Python
def counting_sort_by_digit(data, digit_pos):
    """指定した桁で分布数えソートする"""
    base = 10
    count = [0] * base
    for value in data:
        digit = (value // digit_pos) % base  # 指定桁の数字を取り出す
        count[digit] += 1
    for i in range(1, base):
        count[i] += count[i - 1]
    output = [0] * len(data)
    for i in range(len(data) - 1, -1, -1):
        digit = (data[i] // digit_pos) % base
        position = count[digit] - 1
        output[position] = data[i]
        count[digit] -= 1
    return output

def radix_sort(data):
    """基数ソート: 各桁で分布数えソートを繰り返す"""
    if len(data) <= 1:
        return data[:]
    max_val = max(data)
    result = data[:]
    digit_pos = 1  # 1の位からスタート
    while digit_pos <= max_val:
        print(f"  {digit_pos}の位でソート: {result[:10]}...")
        result = counting_sort_by_digit(result, digit_pos)
        digit_pos *= 10  # 次の桁に進む
    return result

# --- 実行 ---
test_data = [170, 45, 75, 90, 802, 24, 2, 66]
sorted_result = radix_sort(test_data)
print(f"結果: {sorted_result}")

students = [
    ("鈴木", 80), ("田中", 95), ("佐藤", 80),

# sorted は安定ソート

result2 = sorted(students, key=lambda x: x[1], reverse=True)

例題 例題2 やってみよう 解答

末尾から配置するループ for i in range(len(data) - 1, -1, -1): を for i in range(len(data)):（先頭から）に変えると、80点グループの順序が逆転する:

末尾から配置（元のコード）:
  80点の順序: ['Sato', 'Suzuki', 'Ito']
  元の順序保持: True  ← 安定ソート

先頭から配置（変更後）:
  80点の順序: ['Ito', 'Suzuki', 'Sato']
  元の順序保持: False ← 不安定になる

分布数えソートが安定であるためには、累積度数を「右端の次に入る位置」として使い、入力を末尾から走査する必要がある。先頭から走査すると、同じキーの要素のうち 先に出てきたもの が累積度数の 後ろ の位置に置かれてしまい、入力順が反転する。安定性は単独データでは差が出ないが、多段ソート（基数ソートや「数学順 → 同点なら英語順」など）では結果を大きく左右する。例題3の基数ソートが正しく動く前提でもあるので、ここでの「末尾から」は省略不可。

例題 例題3 やってみよう 解答

入力を test_data = [329, 457, 657, 839, 436, 720, 355] に変えて radix_sort を実行したときの、各桁ソート後の状態:

  1の位でソート: [329, 457, 657, 839, 436, 720, 355]...
  10の位でソート: [720, 355, 436, 457, 657, 329, 839]...
  100の位でソート: [720, 329, 436, 839, 355, 457, 657]...
結果: [329, 355, 436, 457, 657, 720, 839]

各桁の動きを追うと、1の位ソート後は [720, 355, 436, 457, 657, 329, 839] となり1の位が 0,5,6,7,7,9,9 と昇順、10の位ソート後は [720, 329, 436, 839, 355, 457, 657] となり十の位が 2,2,3,3,5,5,5 と昇順に並び替えられ、100の位ソート後に最終結果 [329, 355, 436, 457, 657, 720, 839] が得られる。基数ソートが正しく動く鍵は、各桁の分布数えソートが「安定」であること（例題2）。下位の桁で揃えた順序を、上位の桁で「同点ならその順を保ったまま」並べ直すから、桁を順に処理するだけで全体が完全にソートされる。最大値の桁数を d、データ数を n とすると計算量は O(d × n)。整数キーで d が小さければ Timsort より高速になる。
